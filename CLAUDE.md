# Глечики — правила для Claude

Радіо й ігри для компанії друзів: сервер C# .NET 10 (`src/Hlechyky`), клієнт — чистий JS/CSS без фреймворків (`web/`),
SQLite (`data/hlechyky.db`), ефір — liquidsoap + Icecast. Тексти, коментарі, коміти й звіти — **лише українською**, у стилі
наявного коду. Як усе влаштовано — `README.md` (розділи «Як це працює», «Структура»), ігри — `docs/games/README.md`.

@~/.claude/hlechyky-private.md

## Де що
- `src/Hlechyky/` — сервер; `Endpoints.cs` — API; `Games/` — ігрова платформа, `Games/Impl/` — окремі ігри.
- `web/` — клієнт; `web/games/<id>/` — ігри. Статика віддається з диска наживо (F5), рестарт сервера — лише після C#.
- `tests/Hlechyky.Tests/` — xUnit (~7 тис. тестів); `tests/koliya-js/` — JS-тести Колії.
- `docs/games/` — `ARCHITECTURE.md`, `PROTOCOL.md`, `TESTING.md`; `specs/<гра>.md` — контракт кожної гри. Великі
  документи цілком не читати: `grep -n` за розділом, потім Read з `offset/limit`.
- Секрети — лише в `appsettings.Local.json` (не в git), зразок — `appsettings.Local.example.json`.

## Збірка й тести
- Збірка: `dotnet build src/Hlechyky/Hlechyky.csproj -v q -nologo -nodeReuse:false 2>&1 | tail -20`.
- **Тести — свої під задачу.** Змінив логіку (C#, правила гри, розрахунки, API) → тест у `tests/Hlechyky.Tests` і
  `./test.cmd` (PowerShell: `.\test.ps1`): він ганяє лише класи зі змінених тестових файлів. `test.ps1 <Назва>` — за
  назвою, `-List` — показати, `-All` — увесь набір. Голий `dotnet test` без фільтра — теж увесь набір.
- Увесь набір, дев-сервер і браузер — лише після великого шматка, перед злиттям/пушем або на прохання.
  Дрібне (текст, стиль, число, перейменування) — перечитати diff, для C# максимум `dotnet build`.
- У звіті чесно: які тести додав, чи зелені, чого не ганяв.
- **Ніколи не вмикати звук** під час перевірок (кнопка «Врубити», аудіо ігор): `audio.muted = true` до `play()`.

## Git
- В одній теці часто працюють кілька сесій: комітити лише своє (`git add <файли>`). Ніколи `git add -A`, `commit -a`,
  `stash`, `checkout -- .`, `reset --hard`, `clean` — зітре чужу роботу.
- Збірки й тести паралельних сесій — у свою теку: `--artifacts-path .art/<назва>`, інакше `obj\` б'ються.
- Велике й довге — окремий worktree зі своїм `appsettings.Local.json` (інший порт, вимкнені AutoDj/DjBot/Deploy/Ad):
  без нього локальний сервер почне керувати живим ефіром.
- Коміти — з git-ім'ям, що вже є в конфігу: без `-c user.email`, `--author`, `GIT_AUTHOR_*`. Без `Co-Authored-By` і
  будь-яких позначок Claude чи ШІ.
- **Пуш і деплой — лише з окремого «так» у чаті на кожен раз.** Попередній дозвіл не переноситься на наступний.
- `web/sitenews.js` («Що нового») і `web/history-data.js` (історія) правляться лише під час збирання релізу — у
  звичайній роботі їх не чіпати (паралельні гілки б'ються саме тут).
- Репо публічне: у коміти, коментарі й тести — без ніків друзів, ключів і прод-конфігу.

## Код
- Правила — на сервері (`Ctx.Clock`, `Ctx.Rng`); клієнт лише малює й передбачає.
- Нові поля збереження — необов'язкові: старе збереження з проду читається як «цього ще не було».
- Натиски, за які дають нагороди, — лише `isTrusted`.
- Ширина 375 px без горизонтального скролу; `prefers-reduced-motion`.
- Назви — барвисті українські, а не загальні.

## Пастки Windows і інструментів
- Bash-команда ≳8 КБ падає з «unexpected EOF» — довге писати Write-ом у файл і запускати файлом.
- Робоча копія в CRLF: `sed -i` у Git Bash переводить файл у LF. Правити Edit або Python-латкою з нормалізацією кінців
  рядків і `assert count == 1`.
- Escape-коди Unicode (` `, `♨`…) Edit/Write може записати справжнім символом — після правки перевір байти
  (`grep -n … | cat -A`).
- `python -c "…"` у Bash розкриває `$x` — латки з `$` лише файлом. Python: `-I -X utf8 скрипт.py </dev/null`, без
  `python -` і heredoc в одній команді (висне REPL).
- `dotnet` за іменем не вбивати (`Stop-Process -Name dotnet`, `taskkill /IM dotnet.exe`) — на цій машині живе й прод;
  свій процес — за PID або шляхом до dll.
- Headless Chrome після знімків закривати разом із деревом процесів (WebGL на swiftshader їсть CPU).
- Посилання — повні: `http://127.0.0.1:<порт>/…` або абсолютний шлях, не відносний.
