# Проміжний формат `fura-osm/1`

Файл `data/fura/maps/<id>.osm.json.gz` — один JSON у gzip (Житомир: 11,7 МБ JSON → **2,95 МБ gzip**). Його пише
`build.py`; з нього роблять прев'ю (`preview.py`), мапу гри в теперішньому форматі (`kray.py` → `<id>.json`) і далі
— «дорогу 2.0» та рендер міста. Чанків нема: усе місто вміщається в бюджет ≤ 5 МБ, а різати на квадрати по 1 км
зручніше вже під потребу рендеру (з цього ж файлу, без повторного завантаження).

Збірка стала: той самий кеш → той самий файл байт у байт (gzip без часу, обходи множин відсортовані).

## Осі й одиниці

- Метри. **x — схід, z — північ, y — висота над рівнем моря** (Copernicus, геоїд EGM2008). Як у грі: `yaw` 0 = +Z.
- Проєкція — поперечний Меркатор WGS84 з осьовим меридіаном через `proj.lon0`, нуль — у (`proj.lat0`, `proj.lon0`).
  На 10 км від центру масштаб відходить від 1 на ~1e-6, кути правдиві.
- Координати округлені до 0,1 м.
- Шлях OSM → гра: `proj.py` (`Proj(lat0, lon0).fwd(lat, lon)` → `(x, z)`; `inv` — назад).

| поле | що |

| `attribution` | `{osm, dem}` — підписи, які гра **мусить** показувати (див. README, «Ліцензії») |
| `source` | `{osm_base` (час знімка OSM), `bbox` [пд, зх, пн, сх], `dem` [тайли], `canopy` (висота крони, м), `tool`, `tol` (допуск спрощення доріг, м)`}` |

## `height` — сітка висот

```
{ x0, z0, step: 30, nx, nz, y0, scale: 0.1, enc: "u16le-base64", order: "iz*nx+ix, iz=0 — південь (z0)", data }
```
Вузол сітки (ix, iz) — точка (x0 + ix·step, z0 + iz·step); висота = `y0 + u16[iz*nx + ix] × scale`. Між вузлами —
білінійно. Це **земля**, а не DSM: Copernicus GLO-30 — модель поверхні (дахи, крони), тож `build.py` віднімає крону
під лісом OSM (меряє її сам на краях лісу, Житомир — 13,2 м), а будинки, гаї й лісосмуги, які прогресивний
морфологічний фільтр визнав «не землею» (31 % клітин), заповнює з сусідів. Річкові долини й каньйон Тетерева лишаються.

## `edges` — ребра графа доріг

Вершина графа — перехрестя (вузол OSM, спільний для ≥ 2 доріг), кінець дороги або край мапи. Ребро — дорога між
двома вершинами; шматки з однаковими атрибутами вже злиті через вершини степеня 2. Міст чи тунель — завжди окреме
ребро (у OSM це окремий шлях).

| поле | що |
|---|---|
| `id` | `"w<osm way>-<k>"` — шлях OSM і номер шматка (стабільне між перезборами, поки не змінились дані) |
| `a`, `b` | вершини на кінцях; **односторонні — завжди a → b** (`oneway=-1` уже розвернуто) |
| `pts` | `[[x, z, y], …]` від `a` до `b` включно; спрощено Дугласом — Пекером з допуском `source.tol` (1,5 м) |
| `len` | довжина в плані, м |
| `cls` | клас `highway`: motorway, trunk, primary, secondary, tertiary, `*_link`, unclassified, residential, living_street, service, track, road, busway |
| `oneway` | `1` — лише a → b (зокрема неявно: кільця, motorway) |
| `ring` | `true` — частина кільця (`junction=roundabout|circular`) |
| `link` | `true` — з'їзд (`*_link`) |
| `name`, `ref` | назва, номер траси (`Т-06-14`, `М-06`…) |
| `lanes`, `width`, `maxspeed` | числа: смуг, ширина м, км/год (`UA:urban` → 50 тощо) |
| `surface`, `tracktype`, `service`, `access`, `lit`, `sidewalk` | як в OSM |
| `bridge`, `tunnel` | значення OSM (`yes`, `viaduct`, `culvert`, `building_passage`…) |
| `layer` | шар (міст над дорогою — 1 тощо) |
| `dual` | розділена проїзна частина: відстань між осями двох односторонніх ребер, м |
| `pair` | ребра другої проїзної частини навпроти (до 4) |

Висоти `y` у `pts`: земля з сітки, ковзне середнє за 50 м уздовж дороги, кінці точно на висоті вершин; міст і
тунель — прямою між кінцями. Кінець мосту піднято на берег (найвища земля в 0–40 м за ним), проліт — не нижче
землі під ним + габарит (6 м для довгих, 8 % довжини для коротких), сусідні вершини — насипом не крутіше 7 %
(такі вершини мають у `nodeTags` позначку `embank`).

**Розділені дороги.** У Житомирі проспекти намальовані двома односторонніми лініями всього ~5 м одна від одної
(медіана 5,2 м, 620 ребер, 74 км). Якщо малювати кожну на повну ширину, вони злипнуться. Рендер має брати пару
(`dual` + `pair`) як одну дорогу з розділювачем, а граф для руху й навігації лишити як є: кожна проїзна частина —
своє одностороннє ребро.

## `nodeTags`

Перший запис кожної вершини — `{k: "end" | "join" | "cross" | "ring", deg, link?}`: кінець (степінь 1), стик двох
різних доріг (степінь 2, атрибути різні), перехрестя (≥ 3), вершина кільця. Далі — ознаки з вузла OSM, якщо є:
`traffic_signals`, `stop`, `give_way`, `crossing`, `motorway_junction` (з `ref`/`name`), `mini_roundabout`, а також
`{k: "embank", h}` — насип до мосту на `h` м.

## `rings`

`{id, x, z, r, name?, nodes: [вершини], edges: [ребра кільця], exits: [ребра, що виходять], mini?}` — центр і
середній радіус кільця. `mini: true` — міні-кільце в одній вершині (`r` = 0).

## `points`

`{k, x, z, y, edge, ref?, name?, crossing?}` — світлофор, перехід тощо в середині ребра `edge`.

## Інші шари

- `paths`: `{cls: footway|path|pedestrian|steps|cycleway|bridleway, pts: [[x, z]], name?, surface?, bridge?}`.
- `rails`: `{k: rail|tram|light_rail|narrow_gauge|disused|abandoned, pts: [[x, z, y]], service?, usage?, name?,
  electrified?, gauge?, bridge?, tunnel?, layer?}` — висоти як у доріг (без підйому мостів).
- `waterways`: `{k: river|stream|canal|ditch|drain, pts: [[x, z]], name?, width?, tunnel?}` — вісь русла;
  широкі річки й водосховища ще й площами `areas` з `k: "water"`.
- `areas`: `{k, outer: [[x, z]], holes?: [[[x, z]]], name?}`; `outer` — проти годинникової, дірки — за, без повтору
  першої точки. `k`: water, wood, park, grass, pitch, wetland, cemetery, farmland, parking, plaza, residential,
  industrial, commercial, retail, garages, railway, construction, brownfield, military, education, religious,
  quarry, landfill.
- `buildings`: `{id: "w…"|"r…", k (значення building: yes, house, apartments, industrial…), y (земля — найнижча
  під контуром), pts, holes?, lv? (поверхів), h? (висота, м), mh? (min_height), rl? (поверхів даху), roof?
  (roof:shape), name?, addr? ("вулиця 12")}`. Висота для рендеру: `h`, інакше `lv × 3 м` (+ дах), інакше за типом.
- `pois`: `{k, osm: "way/123", x, z, name?, area? (м²), brand?}`; `k`: station, marketplace, fuel, bus_station,
  industrial (названа промзона), `shop:wholesale|mall|supermarket|doityourself|trade`. За `osm` місця гри вибирають
  у `cities.py`.
- `labels`: `{k: city|suburb|neighbourhood|village|…, name, x, z}`.

## Розміри (Житомир, gzip по шарах)

будинки 1,02 МБ · ребра 0,65 · площі 0,54 · висоти 0,32 · вершини 0,17 · пішохідні 0,12 · решта < 0,1.
