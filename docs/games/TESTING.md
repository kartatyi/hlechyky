# Тести ігрової платформи

## 1. Де і як

- Проєкт `tests/Hlechyky.Tests` (xUnit, .NET 10), посилання на `src/Hlechyky/Hlechyky.csproj` +
  `FrameworkReference Microsoft.AspNetCore.App`.
- Запуск: `dotnet test tests/Hlechyky.Tests/Hlechyky.Tests.csproj` (з кореня репозиторію). У CI — той самий
  рядок після `dotnet build`.
- Один файл тестів на клас платформи (`Platform/RoomsTests.cs`) і на гру (`Games/ChessTests.cs`).
- Імена методів — латиницею, читабельно: `Castling_is_illegal_through_check`. `DisplayName` не потрібен.
- Тести **не** запускають веб-сервер і **не** чіпають SignalR. Усе тестується через `Rooms`/`Game`/`Economy`
  напряму. Інтеграція з браузером — руками і QA-агентом (див. PLAN.md).
- Жодного `Thread.Sleep`, `Task.Delay`, `DateTime.UtcNow`, `Random.Shared` у коді, що тестується: час —
  `IClock`, випадковість — `Ctx.Rng`, чекання — `FakeClock.Advance()`.

## 2. Підтримка (`tests/Hlechyky.Tests/Support/`)

- `TempDb` — `Db` на тимчасовому файлі (`Path.GetTempFileName()`), видаляється в `Dispose`. `:memory:` не
  годиться: `Db` відкриває з'єднання на кожен виклик.
- `FakeClock : IClock` — `UtcNow` виставляється руками, `Advance(TimeSpan)`.
- `FakeStore : IGameStore` — словник у пам'яті.
- `RoomHarness` — обгортка над `Rooms` для тестів гри:
  ```csharp
  var h = new RoomHarness("chess", options: new { variant = "classic" }, seed: 42);
  h.Join("Оля"); h.Join("Петро");            // WhenFull → стартує
  var r = h.Act(0, "move", new { from = "e2", to = "e4" });   // seat 0
  r.Ok.Should().BeTrue();
  var v = h.View(1);                          // вид для місця 1 (dynamic або JsonElement)
  h.Tick(times: 10);                          // для реалтайму: FakeClock.Advance(TickMs) + Tick()
  h.Room.Status.Should().Be(RoomStatus.Finished);
  h.Outbox.OfType<Journal>().Last().Text.Should().Contain("1:0");
  ```
  `Act` приймає анонімний об'єкт і серіалізує в `JsonElement` — так само, як приходить із хаба.
- `Views.Json(obj)` — серіалізує вид у той самий JSON, що піде на дріт (camelCase), і повертає `JsonElement`
  — щоб тести перевіряли форму на дроті, а не C#-типи.

## 3. Що обов'язково для платформи (WP0/WP1)

**Rooms**
- створити → господар на місці 0, статус `lobby`, у `rooms` є; Private — нема;
- сісти другим → `WhenFull` стартує, `Start()` викликано один раз, `Journal` «сіли грати в …»;
- один нік — одне мультиплеєрне місце; соло не рахується;
- ліміт кімнат; сісти в повну; сісти в чужу приватну — помилка;
- `ByHost`: старт не господарем — помилка; менше MinPlayers — помилка; старт → `playing`;
- `Act` не в свою чергу/не сидячи/після Finish — помилка, гра не викликана;
- `Finish` → статус, `result`, `Journal`, `RoomFinishedEvent` рівно один; другий `Finish` — ігнорується;
- `Rematch` → місця обернулись, `Round++`, `Start()` знову, ставка списана знову;
- `LeaveRoom` у Playing → `OnLeave` → техпоразка; у Lobby → місце вільне; порожня кімната зникла;
- `DropIfGone`: після disconnect місце тримається grace-час, потім звільняється;
- прибирання: `lobby` > 30 хв, `finished` > 15 хв;
- ставка: бракує черепків → не сів; списано на старті; переможець отримав банк; нічия → повернення;
  ідемпотентність refs (подвійний Finish не подвоює виплату);
- Outbox: `Hidden` → по виду на з'єднання, види різні для різних місць; не-Hidden → один вид;
- payload > 8 КБ → відкинуто.

**TickEngine**
- кімната з `TickMs=100`: за `Advance(1s)` — рівно 10 тиків, не 11; пропущений час не надолужується;
- виняток у `Tick` → кімната `finished` нічиєю з текстом, інші кімнати тикають далі;
- `Finished`/`Lobby` кімнати не тикають.

**Economy**
- `Grant` з тим самим `ref` двічі → `Duplicate`, баланс +1 раз;
- `TrySpend` при нестачі → false, баланс не змінився; 20 паралельних `TrySpend(1)` при балансі 10 → рівно 10 true;
- стелі: 13-й `listen` за день → `Capped`; 11-та партія за день → без нагороди;
- `Rebuild()` після ручного псування `wallets` відновлює суму леджера;
- `nick_key`: «Оля» і «оля» — один гаманець.

**Ratings/Leaderboards/Achievements/Daily/Words**
- Ело: 1000 vs 1000, перемога → 1016/984; нічия → без змін; K=48 у перших 10;
- таблиця за період не бачить старіших записів;
- ачівка видається один раз, дає черепки один раз, `Journal` рядок є;
- `Daily.Today()` для Europe/Kyiv на 23:59 і 00:01 — різні дні; сід детермінований;
- Words: 5-літерне слово з `uk-5.txt` валідне, слово з апострофом не приймається, нема словника → `Loaded=false`
  і гра відповідає «нема словника», а не падає.

## 4. Що обов'язково для кожної гри

1. **Правила.** Кожна гілка `Act`: легальний хід міняє стан як треба; нелегальний — `Fail` і стан не
   змінився (порівняти `View` до/після). Усі умови кінця (перемога кожного місця, нічия, техпоразка).
2. **Вид.** `View(seat)` для кожного місця і `View(null)`: форма на дроті (через `Views.Json`) відповідає
   spec; у `Hidden` іграх чуже приховане відсутнє (не `null` — відсутнє або замасковане, як каже spec).
3. **Детермінізм.** Та сама послідовність дій із тим самим сідом → той самий стан (серіалізований вид).
4. **Реалтайм.** Симуляція N тиків із заданими вводами доходить до очікуваного результату (зіткнення,
   гол, вибух). Продуктивність: 1000 тиків на максимальній кількості гравців — < 2 с (`Stopwatch`,
   `[Trait("Category","Perf")]`).
5. **Рематч.** Після `Finish` → `Rematch` → `Start()` дає чистий стан, рахунок серії зберігається, якщо spec
   так каже.
6. **Save/Load** для Persistent: `Load(Save())` → еквівалентний вид.
7. **Специфічні** зі spec гри (перфт для шахів, обов'язкове взяття в шашках, розкладка кораблів тощо).

Мінімум — 15 тестів на просту гру, 40+ на шахи/шашки/ерудит/дурень/мафію.

## 5. Ручна перевірка (перед здачею гілки)

- `dotnet build src/Hlechyky/Hlechyky.csproj -c Release` — без нових попереджень;
- `dotnet test` — зелений;
- сервер із worktree на порту 8090 (`appsettings.Local.json` там уже налаштований), дві вкладки:
  `http://localhost:8090` і `http://127.0.0.1:8090` (різні localStorage → різні ніки), зіграти партію до
  кінця, «Ще раз», встати посеред партії, оновити сторінку посеред партії (F5 → місце має вціліти в grace),
  подивитись збоку третьою вкладкою;
- на вузькому вікні (≤ 480 px) картка не ламає розкладку, керування є для пальця.
