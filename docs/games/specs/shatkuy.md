# Шаткуй!

Наш Fruit Ninja (записка 💡 #62: «звичайна різалка, без ставок» для Мар'яни після плутанини з гнилим гарбузом у
«Кавунах на ярмарку»). Дядько Глек підкидає з воза овочі й фрукти, людина шаткує змахом пальця чи миші.

Код: `src/Hlechyky/Games/Impl/ShatkuyCore.cs` (розклад, ігровий час), `Impl/Shatkuy.cs` (ігри, таблиця дня),
клієнт `web/games/shatkuy.js` + `.css` (префікс `shk-`: `sk-` уже зайняла «Скирта»), тести `tests/Hlechyky.Tests/Games/ShatkuyTests.cs`.

## 1. Ігри

| id | назва | де | правила |
|---|---|---|---|
| `shatkuy` | 🔪 Класика | Соло → Сам собі, родина «Шаткуй!» | 3 промахи — кінець; глек — одразу кінець; кожні 100 очок повертають життя |
| `shatkuy-fair` | 🎪 Ярмарок | там само | 60 с, без життів; ❄ мороз, ✨ ×2, 🌽 злива, 🍉 великий кавун; глек −10 |
| `shatkuy-zen` | 🍃 Дзен | там само | 90 с, самі плоди |
| `shatkuy-daily` | ☀ Шаткуй дня | Щоденні | 45 с, правила Ярмарку, той самий віз для всіх (сід від дня), одна спроба |

Усі — Solo, Private, Persistent (рекорд і кількість партій; у щоденної — підсумок дня), реалтайм `TickMs = 50`.

## 2. Розклад і час

- `ShatkuyPlan` — лінивий детермінований розклад (SplitMix64 від сіду): хвилі «віяло» / «низка» / «навхрест», темп
  росте з часом. Плід: `at` (ігрова мс вильоту), `d` (політ), `x0 → x1`, `h` (верхівка дуги), `sp` (оберти).
  Дуга: `y = H + r − (h·H + r)·4s(1−s)`, `s = (g − at)/d` — та сама в браузері (`where`).
- **Ігровий час** g: мороз (5 с справжнього часу) іде з темпом 0,5 — `ShatkuyCore.Game(t, frost)`, та сама формула в
  `shatkuy.js gameMs`. Таймер режимів на час теж ігровий: мороз подовжує хвилину.
- Сервер показує розклад на `LookMs = 1000` наперед, щоб браузер малював виліт вчасно.
- Злива — 18 плодів з боків, з власного сіду від номера зливи (у щоденній однакова для однакових змахів).
- Великий кавун — за 7 с до кінця, летить 5 с; удар — раз на змах, не частіше 60 мс, до 30.

## 3. Розріз і очки

Браузер шле `input('cut', { c: [[id, w], …] })`, w — номер змаху. Сервер приймає, якщо плід у повітрі за його ігровим
часом: `at − 100 ≤ g ≤ at + d + LagMs (600)`. Звичайний плід — 1 очко; комбо (одним змахом): третій +3, кожен
наступний +1 (комбо з n дає n зверху). ×2 множить усе. Геометрію сервер не перевіряє — лише час (чесність на рівні «плід
справді був у повітрі»; бота, що рахує дуги, це не спинить — для друзів досить).

## 4. Клієнт

Спрайти плодів малюються раз на розмір поля (малюнки звичайних — з «Кавунів»), половинки, бризки, плями на дошці
(6 с), кільця соку, спалах розрізу, уламки глека, конфеті на рекорд, тексти «+1», «Комбо ×n» біля останнього розрізу.
Лезо — стрічка, що звужується до хвоста (золота під ×2, крижана під морозом). Стартовий кавун на «ready»: розрізав —
поїхали. Звук — синтез WebAudio, типово вимкнено (🔇). Джойстик: лівий стік водить лезо, Ⓐ/RT/RB — тримай і веди.

## 5. Нагороди

Звичайні: `Ctx.Score` (таблиця, більше — краще), `Award(score / 50, ≤ 10, "shatkuy:<раунд>")` через денну стелю
нагород і звичайна виплата за партію. Щоденна: таблиця `shatkuy_daily` + `IDailyPoints`, `daily:shatkuy-daily`.
Пішов посеред щоденної — спроба зарахована з тим, що встиг (`Unwatched`), щоденний глек — з першого тіку нової кімнати.

## 6. Ачівки

`shatkuy-combo` комбо ×6 · `shatkuy-classic` 250 у Класиці · `shatkuy-big` 25 ударів по великому кавуну ·
`shatkuy-clean` 150 у Ярмарку без жодного глека. Бот-калібрування (`SHATKUY_CALIB=1`): «людина» в Ярмарку ~190,
у Дзені ~230, у Шаткуй дня ~115 — справжні люди нижче.
