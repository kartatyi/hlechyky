# Клавоперегони: тренування (`typerace-solo`)

Соло-варіант Клавоперегонів: той самий уривок, той самий суддя, але сам на сам із секундоміром, особистим
рекордом і таблицею «знаків за хвилину». Живе в одному модулі з столом (`Client: "typerace"`), тому весь spec —
в одному файлі: [typerace.md](typerace.md).

Де що шукати саме про соло:

- паспорт (`GameInfo`) — §1, друга таблиця;
- фази `pick → ready → go → done`, збереження (`Save`/`Load`, `v: 1`), рекорд і `Ctx.Score` — §2.2;
- дії `go { length, source }` і `stop {}` з текстами відмов — §3;
- поля виду `me`, `noTexts` — §4.1;
- панель `pick`, кнопки «Ще раз» / «Змінити» / «Кинути виклик друзям» — §6.1, §6.6;
- тести 56–62 — §8;
- чому це окрема гра, а не «стіл на 1–10» — §9, п. 1.
