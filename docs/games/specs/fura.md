### Фізика

- Осі: +Y вгору, +Z вперед, праворуч −X. Маса тягача 7,5 т, причепа 6,8 т + 12 т вантажу (низько).
- Підвіска Rapier множить силу на масу шасі, тому жорсткість «на кілограм»; гальмо — стеля імпульсу на колесо за крок.
- Промені коліс бачать лише нерухоме (`onlyFixed`): не свій тягач/причіп і не конуси.
- Відчеплений причіп стоїть на «ногах» (колайдер вмикається без тягача) на 1,30 м — вище рами тягача (1,22), тож тягач
  заїжджає під нього заднім ходом. Зчепити — коли шворень над сідлом ближче 0,45 м, курси різняться < 0,9 рад, швидкість < 1,5 м/с.
- Коробка: автомат 12 передач (лише для обертів і тяги), ручна 6 + R. «Аркадна» задня: стоїш і тримаєш гальмо 0,45 с —
  вмикається R, і гальмо стає газом назад. H-перемикач бере коробку, лише коли в ньому ввімкнули передачу.
- Вантаж: прискорення причепа (згладжене 60 мс) у його осях; шкода лінійна від перевищення порогів — вертикаль 2,0 ×3,
  бокове 4,5 ×0,5, поздовжнє 5,0 ×0,8, ×8 %/с. Після телепорту датчик мовчить 30 кроків.
  Заміри (24.10): горби 20–45 км/год −7…9 %, поворот 40 км/год на пів керма −11 %, гальмо з 40 до нуля — 0 %.

## Етап 1 — соло-рейс: контракт сервера (25.10)

Рішення користувача: 150–500 🏺 за рейс, стеля 2000 🏺 на день; причіп у відправника; пагорби; Глек голосом.

### Мапа `data/fura/maps/kray.json`
Одна мапа на обидва боки: браузер будує з неї світ (рельєф — сам із `seed`), сервер — граф і зони.
- `nodes` — точки [x, z]; `roads` — `{id, kind, a, b, via}`: полілінія a → via… → b. **Довжина дороги для сервера —
  сума відрізків полілінії** (браузер згладжує кути, різниця < 3 %).
- `places` — `{id, title, short, node, yard{x,z,w,d}, docks[{id,x,z,yaw}], depot?, spawn?}`. `yaw` — курс передка
  причепа: 0 = +Z (північ), π/2 = +X. Двір — прямокутник по осях із центром x,z і розмірами w (по X) × d (по Z).
- `cargo` — `{id, title, emoji, mult, fragile, mass, from[], to[]}`. `mult` — множник плати, `fragile` і `mass` —
  для фізики браузера.
- Сервер віддає файл як є: `GET /api/games/fura/map/kray` (application/json).

### Гра `fura` (етап 1)
`GameInfo`: Solo, 1…1, `Start: Immediate`, `Private`, **`TickMs: 250`**, **`Persistent: true`**. Вид — `{ stage: 1, phase, … }`.

**Фази:** `free` (дошка, нема замовлення) → `pickup` (узяв, причіп чекає в боксі відправника) → `haul` (зчеплено
у відправника, везе) → `done` (підсумок) → `free` (нова дошка).

**Дошка** (у фазі `free`): 5 замовлень з `Ctx`-незалежного сіду `hash(день, нік, рейсів_зроблено)` — детерміновано.
Замовлення: `{id, cargo, from, dock, to, km, minutes, pay}`; `from` — місце з `cargo.from`, `to` — з `cargo.to` (≠ from),
`dock` — випадковий бокс відправника, `km` — найкоротший шлях графом між вузлами місць (1 знак), `minutes` =
⌈км / 50 км/год × 60 × 1,5⌉ + 2, `pay` — орієнтовна плата в справжніх черепках (база × Boost, при ціле 100 %, без бонусів).

**Дії (`Act`):**
| дія | коли | що |
|---|---|---|
| `take {id}` | free | замовлення з дошки → pickup, `takenAt` = зараз |
| `cancel` | pickup, haul | без штрафу → free (та сама дошка) |
| `auto` | pickup, тягач ≤ 30 м від боксу | позначка «автозчеп» (−10 %); саме зчеплення робить браузер |
| `rescue` | будь-коли | «поставити на колеса»: наступний стрибок пози до 3 м не телепорт |
| `deliver` | haul | перевірка здачі → done з підсумком і `Award`; не пройшла — `Fail(причина)`, стан той самий |
| `next` | done | → free, нова дошка |

**Телеметрія (`Input pose`)**, до 4/с: `{x, z, v, c, k, rx, rz, ry}` — тягач (x, z), швидкість м/с (v, зі знаком),
зчеплено (c), ціле % (k, 0…100), центр причепа (rx, rz) і його курс (ry). Час знімка — `Ctx.Clock`, не з клієнта.

**Суддя** (константи — у коді, з цими значеннями):
- Швидкість між знімками (dt ≥ 0,15 с): > 160 км/год — «порушення»; > 3 порушень за рейс або одне > 250 км/год →
  рейс недійсний («телепорт»). Стрибок ≤ 3 м одразу після `rescue` не рахується.
- Пауза: dt > 15 с — час між знімками не йде в годинник рейсу; після паузи тягач має бути ≤ 30 м від останньої пози,
  інакше рейс недійсний.
- Підбір (pickup → haul): знімок із c = true, причіп ≤ 12 м від центру боксу відправника.
- Здача (`deliver`): фаза haul; останній знімок свіжий (≤ 2 с), |v| < 0,5 м/с, c = false (відчепився), причіп у дворі
  отримувача (прямокутник, розширений на 15 м) або ≤ 25 м від будь-якого його боксу.
- Час haul (без пауз) ≥ км / 100 км/год; проїдено тягачем у haul (сума відстаней між знімками) ≥ 0,9 × км.
- `k` — лише спадає: рахуємо найменше з надісланого за haul.
- Недійсний рейс: `deliver` повертає `Fail` з причиною людською мовою, рейс скасовується → free.

**Плата:** база = (8 + 9·км) × `mult` × k/100; × 1,1 вчасно (з `takenAt` без пауз ≤ `minutes`); × 1,1 точно в бокс
(центр причепа ≤ 2 м від центру боксу й |ry − yaw| ≤ 0,25 рад); × 0,9 автозчеп; округлити й обмежити 15…50.
k < 20 — «усе розбито», 0. Нарахування — `Ctx.Award(0, база, "fura:<номер рейсу>")`; у `Rewards` для префікса `fura:`
своя денна стеля `Economy:FuraDailyCap` = 200 (база, × Boost = 2000) окремо від `AwardDailyCap`, сума × Boost як у
`award:`. Підсумок у виді: км, час, ціле %, бонуси, база, черепки (× Boost), а що понад стелю — каже `Rewards`
(у підсумку — примітка «денна стеля 2000 🏺»).

**Save/Load:** фаза, дошка, замовлення, стан рейсу (taken/haul, пройдено, порушення, мін k, автозчеп, остання поза),
рейсів зроблено. Посеред рейсу `Load(Save())` дає той самий вид.

### Як реалізовано на сервері (25.10)

Файли: `Impl/Fura.cs` (гра), `Impl/FuraJudge.cs` (суддя, зони, плата — без кімнати), `Impl/FuraMap.cs` (мапа, кеш,
Дейкстра), `Impl/FuraSetup.cs` (HTTP), гілка `fura:` у `Economy/Rewards.cs`, `Economy:FuraDailyCap` у `Config.cs` і
`appsettings.json`. Тести — `FuraTests.cs` (з `FuraRewardsTests`, `FuraPerfTests`) і `FuraJudgeTests.cs`.

Уточнення до контракту — що й чому:
- **`pose` приймається і як `Act`.** Каркас зберігає Persistent-стан лише після `Act`, `Input` — ні. Браузер шле
  `input('pose')` до 4/с, а `act('pose')` — раз на ~5 с і одразу після зчеплення/відчеплення: тоді посеред рейсу збережене
  не відстає (після перезапуску дт < 15 с — звичайна перевірка швидкості, не пауза).
- **Вид летить із тика.** Реалтайм після `Act` видів не шле: дія ставить «змінилось», найближчий тик (≤ 250 мс) розсилає
  вид. Поза сама вид не розсилає — лише події (фаза, порушення, недійсність, нове менше ціле). Кадрів (`frame`) нема.
- **Порядок `deliver`.** Спершу «зіпсовано по дорозі» (телепорт, пауза) → `Fail` і рейс скасовано; далі «тут і зараз»
  (свіжість, зупинись, відчепи, двір) → `Fail`, стан той самий; лише на місці — мін. час і мін. кілометри → `Fail` і
  скасовано. Так випадковий «Здати» посеред дороги рейсу не губить.
- **Знімки ближче 0,15 с** швидкість не міряють: точка відліку стоїть до першого знімка, що далі 0,15 с від неї.
- **`rescue`**: на першому вимірі після нього від стрибка віднімаємо 3 м (а не «до 3 м — пропустити»): чесна їзда
  плюс підйом на колеса не дає порушення. Поблажка — на один вимір.
- **Годинник рейсу** йде з `take` (попередня поза — точка відліку, лише якщо їй ≤ 15 с; інакше відлік із першого знімка);
  швидкість і паузи судяться з `take`, а haul-час, пройдене й ціле — лише після зчеплення.
- **Стеля.** Причина в гаманці — `award:fura:N` (ярлик «нагорода за гру»), лічильник стелі — `fura`, ref —
  `fura:{кімната}:{N}:{нік}`. Що в стелю не влазить цілком, платиться залишком (500 при 1800 з 2000 → 200) з приміткою в тості.
- **Дошка**: id замовлень 1…5; день за Києвом; у free північ дає нову дошку (з тика), `next` — завжди нову (рейсів +1).

Вид (`View`, однаковий місцю й глядачеві):
```
{ stage: 1, map: "kray", phase: "free"|"pickup"|"haul"|"done", trips,
  board: [order…] | null (лише free),  order: order | null (pickup/haul/done),
  trip: { takenAt, sec, haulSec, driven (км), minK, auto, rescue, violations, voided: "причина" | null } | null (pickup/haul),
  pose: { x, z, v, c, k, rx, rz, ry, at } | null (остання прийнята — щоб після перевідкриття поставити тягач туди ж),
  result: { trip, cargo, from, to, km, driven, sec, minutes, k, onTime, exact, auto, broken, base, shards } | null (done),
  cap }                          // денна стеля рейсів у справжніх черепках (FuraDailyCap × Boost)
order = { id, cargo, from, dock, to, km, minutes, pay }   // pay — база × Boost, ціле 100 %, без бонусів
```
