## Б. Палій «коли мене нема»

  нема; змінити — у горні».
- `Away`: палій працює (`AutoKiln`, `ClickerKiln.cs` ~1422), лише коли гончаря нема: ≥ `AwayFrom` (5 хв) без дій руками
  (`_handsAt`, `Clicker.cs:1138`) або натиснуто «Закрити» (`_goneAt != default`). Поки гончар тут — палій не бере ні неповної,
  ні **повної** сушарні (гілка `full` теж мовчить), не чіпає розпису. Палить в обраному розписі, як і зараз. Офлайн-кроки
  (`Clicker.cs:1309` — синхронізація кроками) мусять бачити «гончаря нема».
- `Hands` = нинішнє «вимкнено». `Always` = нинішнє «увімкнено».
- Клієнт: замість галочки «🧑‍🏭 Палій палить сам» (`web/games/clicker-kiln.js:691`, ще `clicker-guild.js:908`) — три кнопки
  🔥 завжди / 🌙 коли мене нема / ✋ лише руками; дія `guild { op: "auto", mode }` (старе `on: bool` приймати далі).
- Порада Глека (`ClickerAdvisor` / `data/clicker/glek-tips.json`): режим `Hands`, сушарня повна ≥ 30 хв → «палій сидить, сушарня
  повна — підмайстри стоять; постав «коли мене нема»».

хвилин «у запасі» (стеля 3 год): гончар вмикає сам кнопкою біля бафів, коли хоче. Використовують Г1, Г3, Г7.

  дарунок другові · натисни фестиваль · розгадай загадку Глека (Д2). Усі три → скриня: 30 хв гри (`PayMinute × 30`), +200 Слави,

  `SparePlan`, чуже відкладене не брати); платить як село. Виконали до кінця тижня — кожному, хто довіз ≥ 5 %, **+10 % до всього**
