# Лелека — crash на всіх (`lelka`)

Сервер: `src/Hlechyky/Games/Impl/Lelka.cs` (стіл), `LelkaCore.cs` (математика), `LelkaBook.cs` (каса, налаштування,
підключення). Клієнт: `web/games/lelka.js` + `lelka.css`. Тести: `tests/Hlechyky.Tests/Games/LelkaTests.cs`.
Контракт задачі — `D:/or-wt/_azart/LELKA.md`.

## 1. Правила

- Стіл веде Дядько Глек за розкладом: **ставки 8 с → політ → «шубовсть» 2 с → пауза 3 с → ставки…** Підсісти можна
  будь-коли; встав — ставка лишається й летить (автозабір спрацює й без людини).
- Під час ставок: сума з гаманця черепків (`Lelka:MinBet` … `Lelka:MaxBet`, типово 10 … 2000; `MaxBet: 0` — без стелі)
  і, за бажанням, «автозабрати на ×X» (×1,01 … ×1000). Одна ставка на людину: нова — замість старої. Скасувати —
  лише до кінця прийому. Черепки списуються в мить «злітаємо» (кінець прийому); не стало — ставку знято, людині рядок `note`.
- Політ: множник `m(t) = e^(0,075·t)`, t — секунди від `startAt` (×2 ≈ 9,2 с, ×10 ≈ 30,7 с, ×100 ≈ 61,4 с, ×1000 ≈ 92 с).
  Будь-коли до падіння — «Забрати»: виграш = ⌊ставка × m⌋, де m — множник на сервері в мить, коли він отримав дію
  (донизу до сотих). Автозабір — сервер сам на тику, щойно m ≥ X, і платить рівно ×X (також коли X дорівнює точці падіння).
  Автозабір можна міняти й посеред польоту; поставив нижче за поточний множник — забирає одразу за поточним.
- Точка падіння вирішена **на початку прийому ставок** (див. §2). Не забрав до падіння — ставку втрачено.
- `Lelka:Enabled = false` (наживо): нового столу не поставити, ставок не приймає (`on: false` у виді), політ, що вже йде,
  долітає й розраховується. `/api/me` → `lelka` — чи показувати тайл.

## 2. Чесно наперед: seed → crash

1. На початку прийому сервер бере `seed` — 32 випадкові байти (`RandomNumberGenerator`), записані 64 hex-символами
   малими літерами, — і показує `hash = sha256(seed)`: SHA-256 від **UTF-8 байтів рядка** seed, 64 hex малими.
2. Після падіння в кадрі з'являється `seed`. Перевірка: `sha256(seed) == hash` (того самого раунду) і точка падіння —
   за формулою:

```
n     = ціле з перших 13 hex-символів seed          // 52 біти, 0 … 2^52 − 1
cents = ⌊ 96 · 2^52 / (2^52 − n) ⌋                  // ціле ділення; 96·2^52 < 2^63
cents = min(max(cents, 100), 100000)
crash = cents / 100                                  // ×1,00 … ×1000
```

JS для «ⓘ» (точно, на BigInt):

```js
async function lelkaCheck(seed, hash) {
  const buf = await crypto.subtle.digest('SHA-256', new TextEncoder().encode(seed));
  const hex = [...new Uint8Array(buf)].map(b => b.toString(16).padStart(2, '0')).join('');
  const n = BigInt('0x' + seed.slice(0, 13)), two52 = 1n << 52n;
  let cents = 96n * two52 / (two52 - n);
  if (cents < 100n) cents = 100n;
  if (cents > 100000n) cents = 100000n;
  return { ok: hex === hash, crash: Number(cents) / 100 };
}
```

Розподіл: `P(crash ≥ x) = 0,96 / x` для будь-якого x ≥ 1,01 на сітці сотих — тож за будь-якого автозабору гравцям
повертається 96 % (перевага дому 4 %). ×1,00 — у ≈4,95 % раундів: 4 % «одразу» (n < 0,04·2^52) і ще ≈0,95 % — точки
між 1,00 і 1,01, які на сітці сотих теж ×1,00. Раунд на ×1,00 падає в ту саму мить, що злітає: забрати не встигне ніхто.
Стеля ×1000 — у ≈0,1 % раундів.

## 3. Протокол

Гра: `GameGroup.Party`, 1…12 місць, `TickMs = 100`, `StartMode.Immediate`, `Hidden` (вид місця має `mine`/`wallet`),
`Coop`, `Score: HigherIsBetter` (у таблицю — чистий виграш раунду). Стіл не закінчується.

**Один спільний стіл на сайт.** Лелека має маркер `ISharedTable`: `CreateRoom('lelka')` (тайл «Сісти до Лелеки») веде за
наявний живий стіл із вільним місцем (посеред польоту — як LateJoin), а коли людина вже за ним — відповідає «Ти вже за
цим столом» із тим самим `roomId`. Новий стіл з'являється, лише коли столів нема або всі 12 місць зайняті. Стіл,
перерваний перезапуском без чистого знімка (Finished), спільним не годиться: людину з нього відпускає й веде за живий
або новий. У каталозі —
`shared: true`. Дивитись (глядачем) можна будь-який.

### Кадр (`frame`, бачать усі, і глядачі)

```
{ phase: 'bets'|'flight'|'crash'|'pause', round, now, until, startAt, k, m,
  crash: null | 2.37, hash, seed: null | '…',
  bets: [{ nick, amount, auto: null|2.0, out: null|1.84, win }],
  history: [{ round, crash }]   // до 20, найновіше першим
}
```

- `now` — час сервера (для поправки годинника), `until` — дедлайн фази (`bets`, `crash`, `pause`; у `flight` — null),
  `startAt` — старт польоту (null у `bets`), `k = 0.075`.
- `m` — множник на сервері в мить кадру: `bets` — 1, `flight` — поточний (завжди нижчий за точку падіння), `crash`/`pause` — точка падіння.
- `crash` і `seed` — лише у `crash`/`pause`; `hash` — завжди (того раунду, що йде).
- `bets` — за сумою донизу. `out` — на чому забрав; `win` — скільки отримав (0 — ще летить чи пролетів).
- Кадри: на кожну зміну (ставка, забрав, фаза) — разом із видами; у польоті ще раз на секунду (синхронізація m).
  Між кадрами клієнт рахує m сам: `e^(k·(t − startAt))` з поправкою `now`.

### Вид (`View(seat)`)

Те саме, що кадр, плюс `mine: null | { amount, auto, out, win }`, `wallet` (вільні черепки: гаманець мінус ставка, ще не
списана; глядач — null), `limits: { min, max }` (`max: 0` — без стелі), `on` (приймає ставки), `note` (рядок для людини:
«Черепків не стало — ставку знято»).

### Дії (`act`)

| дія | payload | коли | відмова |
|---|---|---|---|
| `bet` | `{ amount, auto? }` (auto — число або null) | `bets` до `until` | поза лімітами, бракує черепків, не ціле, кривий авто, фаза |
| `cancel` | — | `bets` до `until` | нема ставки, фаза |
| `cash` | — | `flight`, своя списана ставка, ще не забрав | фаза («Лелека ще на землі» / «Пізно…»), нема ставки, уже забрав |
| `auto` | `{ x: number \| null }` | `bets` до `until` або `flight`, ставка є й не забрана | нема ставки, уже забрав, кривий x |

`cash` відповідає тостом «Забрав на ×1,84: +184 🏺». Відмова — тост, стан не міняється.

## 4. Гроші й перезапуск

Каса `LelkaBook` (як `RouletteBook`): дім платить зі своєї кишені, банк столу каркаса не годиться.
- Кінець прийому: запис раунду в сховище (`lelka:pending`: стіл `{кімната}:{epoch}`, раунд, точка падіння, ставки
  з автозаборами) — тоді списання `lelka-bet:{table}:{round}:{нік}`.
- Забрав — виграш у запис раунду (синхронно) і в гаманець (`lelka-win:…`, поза замком кімнати). Падіння — розрахунок
  раунду тими самими ключами (повтор нічого не платить) і запис прибрано.
- Перезапуск із поверненням столу: стіл долітає з того самого множника (`Resumed` зсуває `startAt`/`until`), каса раунд,
  який тримає живий стіл, не чіпає.
- Сирота (стіл не повернувся): каса на старті й підмітанням раз на хвилину (запис старший за 4 хв) розраховує за вже
  вирішеною точкою: забрав — свій виграш; автозабір ≤ точки — ставка × автозабір; раунд на ×1,00 — програш; решті —
  ставку назад (`lelka-back:…`). Стіл, що повернувся до раунду, якого вже нема в касі, доводить його мовчки.
- Підписи в леджері: «Лелека — ставка / забрав / ставку повернуто».

## 5. Глек, Журнал, ачівки

- Падіння з виграшем від ×10 — рядок Глека в балачку столу й у Журнал («🪶 Лелека: Оля забрав на ×12,40 — +1240 🏺»);
  інакше «пролетів» зі ставкою від 300 — так само. Журнал — не частіше раз на 5 хв на стіл; балачка — рядок на раунд.
- Політ від ×50, на який хтось ставив, — рядок Глека в загальних Балачках сайту.
- Ачівки (лише тим, хто в мить падіння сидить): `lelka-10` «Вище хмар» — забрав на ×10+; `lelka-brave` «На волосинку» —
  забрав щонайбільше за 0,10 до точки падіння.
