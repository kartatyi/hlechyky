`SeatName`: «ліва»/«права».

## Симуляція (на сервері, у дробових одиницях)

- Поле 160 × 100 (ширина × висота), координати `double`. Ракетки: x = 4 (ліва, місце 0) і 156 (права),
  висота 18, ширина 2, швидкість ≤ 60 од/с. М'яч: радіус 1.5, стартова швидкість 60 од/с під випадковим
  кутом ±30° у бік того, хто пропустив (перший раз — випадково), +6% за кожен відбій (макс 160 од/с).
- Відбій від ракетки: кут = (відносне попадання від центру, −1..1) × 60°; від верху/низу — дзеркально.
- Гол: м'яч за x < 0 або x > 160 → очко, пауза 1 с (`serveIn` тиків), новий розіграш.
- Партія до 7. «Готуйсь» 3 с на старті. Тайм-аут раунду — нема.
- Ввід: `Input('move', { dir: -1|0|1 })` (клавіші, утримання) АБО `Input('to', { y: number })` (палець/миша:
  бажана позиція центру ракетки; сервер рухає до неї з обмеженням швидкості). Останній отриманий ввід діє
  до наступного.

- Гол ліворуч → очко правому; пауза; подача в бік того, хто пропустив.
- Ракетка не виходить за поле; `to` рухає не швидше 60 од/с (за 1 тик ≤ 2.4 од).
