# «Хутори» — контракт гри (id `khutory`)

Катан (базова гра) у нашій темі: 3D-діорама «дерев'яна настолка», дуже дружній інтерфейс. Записка 💡 #74 (Smaug).
Цей файл — **єдине джерело правди** для всіх виконавців: сервера (C#), 3D-сцени, картки столу. Розходиться код із
цим файлом — питай оркестратора, а не вигадуй.

## 1. Тема й назви

| Катан | Хутори | id |
|---|---|---|
| ліс / пагорби / пасовище / поле / гори / пустеля | ліс / глинище / пасовище / лан / гори (Карпати) / Дике поле | `forest pit pasture field mountain steppe` |
| деревина / цегла / вівці / зерно / руда | дерево / глина / вовна / зерно / залізо | `wood clay wool grain ore` |
| поселення / місто / дорога | хата / містечко / шлях | `town city road` |

| карти розвитку | грамоти | `dev` |
| лицар / очко / дороги / рік достатку / монополія | Козак / Скарб / Толока / Врожайний рік / Ярмарок | `knight vp road plenty mono` |

Усі назви, кольори, ціни для клієнта — `web/games/khutory/consts.js` (не дублювати).

## 2. Правила (база Катану, без доповнень)

- Гравців 2–4 (людей ≥1, решта — боти «Глек 🤖» через `BoardBots`). Старт — господар (`StartMode.ByHost`).
- Ціни: шлях = дерево+глина; хата = дерево+глина+вовна+зерно; містечко = 2 зерна + 3 заліза; грамота = вовна+зерно+залізо.
- Запас фігур на гравця: 15 шляхів, 5 хат, 4 містечка (містечко ставиться на свою хату, хата повертається в запас).
- Банк: по 19 кожного ресурсу. Якщо на кидку банку бракує ресурсу на всіх, хто його отримує, — не отримує ніхто
  (якщо отримує лише один гравець — бере, скільки лишилось).
- Колода грамот 25: козак ×14, скарб ×5, толока ×2, врожайний рік ×2, ярмарок ×2 (тасує `Ctx.Rng`).
- Грамоту, куплену цього ходу, не можна зіграти (скарб — очко одразу, потай). Не більше однієї зіграної грамоти за хід
  (скарби не грають). Козака можна зіграти й до кидка.
- Чумацький шлях: найдовший безперервний шлях ≥ 5, +2 очки. Найсильніша сотня: ≥ 3 зіграних козаки, +2 очки.
  Нічия — власник зберігає. Шлях розірвали чужою хатою — перерахувати; якщо після цього кілька рівних (і власник уже
  не найдовший) — нагорода нічия (нікому), поки хтось не стане єдиним найдовшим.
- Очки: хата 1, містечко 2, скарб 1, кожна нагорода 2. Перемога — щойно гравець на СВОЄМУ ходу має ≥ `target` очок.
- Розстановка: перший гравець випадковий (`Ctx.Rng`), порядок гри — за місцями від нього. Коло 1 вперед, коло 2 назад;
  кожен ставить хату (правило відстані, будь-де), потім шлях від неї. Друга хата дає по 1 ресурсу з кожного сусіднього
  гекса (крім Дикого поля).
- Правило відстані: жодна хата/містечко не стоїть на сусідній вершині з іншою.
- Шлях — лише в продовження свого шляху/хати/містечка; крізь чужу хату чи містечко продовжувати не можна.
- Хата (поза розстановкою) — лише на вершині біля свого шляху, з правилом відстані.
- Сімка: усі, в кого > 7 карт, скидають половину (донизу) — фаза `discard`, одночасно. Потім той, хто кидав, ставить
  Кармелюка на інший гекс і бере 1 випадкову карту в одного з гравців, чия хата/містечко торкається гекса (вибирає, якщо
  таких кілька; нікого — без крадіжки). На гексі з Кармелюком числа не родять.
- **Дружній Кармелюк** (опція `friendly`, типово так): не можна ставити Кармелюка на гекс, що торкається чужої хати
  гравця з ≤ 2 відкритими очками, — якщо лишається хоч один інший гекс.
- Торгівля — лише в хід поточного гравця, після кидка (фаза `main`): з банком 4:1; з пристанню «3:1» — 3:1;
  з пристанню ресурсу — 2:1 (тим ресурсом). Пристань «твоя», якщо твоя хата/містечко стоїть на одній із двох вершин її ребра.
  З гравцями — пропозиції (§6).

## 4. Геометрія (сервер і стенди рахують однаково)

Гекси «вершиною догори», радіус гекса (центр→кут) = 1. Центр гекса (q, r): `x = √3·(q + r/2)`, `y = 1.5·r` (y — вниз).

- **Гекси** — 19, порядок id: `r` від −2 до 2, усередині `q` від `max(−2, −2−r)` до `min(2, 2−r)`.
- **Вершини** — 54: обходимо гекси за id, кути `i = 0..5` під кутом `−90° + 60°·i` (0 — верх, далі за годинниковою на
  екрані); нова вершина, якщо ключ `(round(x·1000), round(y·1000))` ще не бачили. `vx[id] = [x, y]` (4 знаки).
  `hexes[h].v` — 6 id вершин у порядку кутів.
- **Ребра** — 72: обходимо гекси за id, для `i = 0..5` пара (кут i, кут i+1 mod 6); нове, якщо пари `(min, max)` ще не
  було. `edges[id] = [a, b]`, `a < b`.
- **Берег** — ребра, що належать рівно одному гексу (30). Сортуємо за `t = (atan2(my, mx) + π/2) mod 2π` середини ребра
  (зростання). **Пристані** — на берегових ребрах з номерами `[0, 3, 7, 10, 13, 17, 20, 23, 27]` цього списку.
  Види: 4 × `any` (3:1) і по одній `wood clay wool grain ore` (2:1), випадкова. Для `starter` — фіксовано
  `any wool any ore grain any clay wood any`.
- **Випадкова карта:** земель ліс×4, пасовище×4, лан×4, глинище×3, гори×3, Дике поле×1; числа
  `2 3 3 4 4 5 5 6 6 8 8 9 9 10 10 11 11 12` на всі, крім Дикого поля. Перетасувати, доки жодні два «червоні» (6, 8) не
  сусідять і жодні два однакові числа не сусідять (до 2000 спроб; далі — досить першої умови). Сусіди — гекси зі спільним ребром.
- **Стартова карта** (`starter`), земля і число за id гекса:
  `forest10 pasture2 field9 | field12 pit6 pasture4 mountain10 | mountain9 field11 steppe forest3 pit8 | forest8 mountain3 pasture4 field5 | pit5 forest6 pasture11`.
- Кармелюк на старті — на Дикому полі.

Еталон для перевірки — `web/games/khutory/dev/fixture.js` (`geometry()`, `board()`): та сама геометрія й стартова карта.
Сервер мусить давати рівно ті самі `vx`, `edges`, `hexes[].v` і порт-ребра (тест у C# порівнює з числами з фікстури:
54/72/30, кілька конкретних id).

## 6. Дії (`Act(seat, action, payload)`)

Помилка → `ActResult.Fail("<людською мовою>")`, стан не міняється.

| action | payload | Хто / коли |
|---|---|---|
| `town` | `{ "v": 12 }` | setup (крок town) або main (за ціну) |
| `road` | `{ "e": 30 }` | setup (крок road), main (за ціну), road2 (задарма; після 2-го або коли нема куди — назад у main) |
| `city` | `{ "v": 12 }` | main |
| `roll` | `{}` | фаза roll, поточний |
| `buy` | `{}` | main — купити грамоту |
| `play` | `{ "k": "knight" }` / `{ "k": "road" }` / `{ "k": "plenty", "res": ["wood","ore"] }` / `{ "k": "mono", "res": "wool" }` | поточний: roll (лише knight) або main |
| `discard` | `{ "res": { "wood": 2, "ore": 2 } }` | фаза discard, рівно `me.discard` карт |
| `robber` | `{ "h": 5 }` | must = robber |
| `steal` | `{ "seat": 2 }` | must = steal |
| `bank` | `{ "give": "wood", "get": "ore", "n": 1 }` | main, поточний; n — скільки ОТРИМАТИ (віддає n × курс) |
| `offer` | `{ "give": { "wood": 1 }, "get": { "ore": 1 }, "to": null }` | main. Від поточного — усім (`to: null`) або одному. Від іншого гравця — зустрічна поточному (to ігнорується). ≤ 3 відкриті від гравця |
| `answer` | `{ "id": 3, "ok": true }` | адресат пропозиції: інший гравець — на пропозицію поточного; поточний — на зустрічну (`ok: false` прибирає зустрічну) |
| `deal` | `{ "id": 3, "seat": 1 }` | поточний: здійснити обмін із тим, хто прийняв (для зустрічної — seat = автор) |
| `cancel` | `{ "id": 3 }` | автор пропозиції |

Пропозиція Глека живе до `offers[].until` (≤ `KhutoryBot.OfferWaitMs` = 10 с від появи): хтось прийняв — обмін, інакше Глек сам її прибирає й ходить далі. Людська — до кінця ходу (`deadline`).
| `end` | `{}` | main, поточний |
| `timeout` | `{}` | будь-хто, коли `deadline` минув (§8) |
| `bot` | — | штовхнути бота (`BoardBots.Nudge`, §8) |

Пропозиція: `{ "id", "from", "to": seat|null, "give": {...}, "get": {...}, "acc": [seats], "dec": [seats] }` — `give` —
що дає автор. Перевірка карт — і при створенні, і при `deal` (хтось міг витратити). Кінець ходу чи будь-яка зміна руки,
що робить обмін неможливим, — пропозиція зникає. Пропозицію не правлять: зміна = скасувати й створити нову.

## 7. Події (`events`) — для анімацій і журналу

Кожна зміна стану додає події з наскрізним `seq`. Клієнт анімує ті, що з `seq` > баченого (на першому `mount` — нічого
не анімує, лише запам'ятовує `seq`).

| k | Поля |
|---|---|
| `roll` | `seat, d: [a, b], gains: [{ hex, seat, res, n }]` (gains — що кому дав кидок; порожній на сімці) |
| `build` | `seat, what: "town"|"city"|"road", at` (v або e) |
| `robber` | `seat, hex` |
| `steal` | `seat, from, res` (res — лише злодію й пограбованому; іншим `null`) |
| `discard` | `seat, n` |
| `dev` | `seat, card` (купівля: card лише покупцю, іншим `null`; гра: `play: true`, card відкрито) |
| `trade` | `seat, with, give, get` (with — місце або `"bank"`) |
| `award` | `kind: "longest"|"army", seat` (seat null — нагорода зникла) |
| `turn` | `seat` |
| `win` | `seat` |

## 8. Час, боти, вихід

- **Боти** — як у `Durak`: `BoardBots.Seat` на старті, `SeatBot`, `botIn` у виді, клієнт людини шле `bot`
  (`HGames.send`, без тосту) через `botIn` мс. Бот робить ОДИН крок (одна дія) за поштовх; `botIn` — `BoardBots.ThinkMs`.
  Хвиля 1: простий бот у `KhutoryAuto` (законний і не дурний: розстановка за сумою «крапок», будує, що може, кидає,
  скидає найчисленніше, грабує лідера). Хвиля 2 — розумний `KhutoryBot` (торгує й відповідає на пропозиції).
- **Таймер:** `deadline` = зараз + час на кожну зміну фази/ходу: `main` і кожен крок розстановки (хата, шлях) — повний
  `timer`, решта фаз — `min(timer, 40 с)`; `discard` — один спільний строк. Строк `main` один на хід: козак/Толока посеред
  ходу його не поновлюють, але, повернувшись у `main`, людина має щонайменше 20 с (`Khutory.MainBackMs`). Минув — будь-який
  клієнт шле `timeout`; сервер звіряє з `Ctx.Clock` і робить за того, хто тягне, автохід (`KhutoryAuto`): розстановка —
  найкраща вершина; roll — кинути; discard — скинути найчисленніше; robber/steal — як бот; main/road2 — Глек доробляє хід
  (`KhutoryBot.Step(…, trade: false, cards: false)`, ≤ 12 кроків): будує місто/хату, міняє з банком лише під будову цього
  ж ходу, кладе шляхи (Толока — безкоштовні); грамот не купує й не грає, з людьми не міняється; далі — кінець ходу
  (`ForceEnd`, пропозиції знімаються). Двічі поспіль проспав — `away: true`, далі за нього грає бот, доки не зробить будь-яку
  свою дію сам.
- **Вихід** (`OnLeave`): людина встала посеред партії — її місце стає ботом (`away: true`, нік лишається в `players`,
  журнал «Глек сідає замість …»). Не лишилось людей — партія НЕ кінчається, а стає на **паузу**: місце `away`, тихо (ні
  Глека, ні журналу); штовхати Глеків і слати `timeout` нікому (Act — лише тим, хто сидить). Кімната тримається
  `HoldEmpty` = 10 хв (потім її прибирає Housekeeping, без Finish). Каркас в `OnLeave` не розрізняє «встав» і «відпав»,
  тож розрізняє `HoldAfterLeave = false`: останній встав кнопкою — стіл зникає одразу (без Finish, рейтингу й рядка
  «партію покинули»); відпав зв'язок (Grace 20 с) — стіл чекає.
- **Повернення** (`Rejoin` + `OnJoin`): хто встав чи випав довше за Grace (20 с), сідає назад тим самим ніком на СВОЄ
  місце — з тією ж рукою й грамотами (`Rooms.LateSeat` питає `Game.Rejoin(nick)`, і за порожнім столом на паузі теж);
  `away` знімається, журнал «… повертається на свій хутір», Глек каже `Back`. Стіл стояв на паузі чи зараз його черга —
  строк поточного рішення свіжий (старий минув, поки нікого не було). Чужий нік чужого місця не займе (`LateJoin` — типовий «ні»). Клієнт: глядач, чий нік
  серед `players` з `away`, бачить «🏡 Повернутись на свій хутір» (у шапці — `mod.rejoin`, і в смузі підказки).
- Партія без часу (`timer=none`) — `deadline: null`, `timeout` відмовляє.
- **Перезапуск сервера** (`Resumable`, файли `KhutorySave.cs` і `KhutoryCore.Save.cs`): деплой не обриває партію.
  `Save` — плаский JSON з версією `V` (`KhutorySnap`): ядро цілком (`KhCoreSnap`: поле, руки, грамоти й колода в тому ж
  порядку, банк, фігури, Кармелюк, фаза й розстановка, пропозиції й лічильник їхніх id, останні події з `seq`, журнал,
  статистика), місця (`bots`, ніки, `away`, проспані), строки абсолютним часом (`deadline`, строк main, `botAt`, пільга
  задрімалому), пам'ять Глеків-гравців (своя пропозиція, з якого часу чекає, у якому ході вже пропонував) і прапорці
  Глека-ведучого. Опцій у знімку нема — каркас кличе `Configure` з опціями столу перед `Start` + `Load`. Після `Load`
  ядро бере `Ctx.Rng` нового процесу; Глек-ведучий починає з чистим запобіжником, а всі події до знімка вважає
  почутими (`_heardSeq = seq`) — історію вдруге не озвучує; клієнт бачить ті самі `events`/`seq`/`log` і не
  переанімовує старе. `Resumed(pause)` зсуває на паузу строк ходу, строк main, `botAt`, пільгу й очікування відповідей
  Глеком — пауза не з'їдає нічий час. Нове поле — нова властивість DTO (старий знімок дасть типове значення).

## 9. Кінець партії

`over`: `{ "winner": 2, "reason": "points" | "left", "points": [повні очки за місцями], "stats": {
"dice": [11 чисел — скільки разів випало 2..12], "sevens": 9, "rounds": 14,
"timeline": [[очки за місцями після кожного кола]], "seats": [{ "seat", "trades", "got", "stolen", "robbed",
"built": { "road", "town", "city" } }] } }`. У `over` скарби всіх відкриті. `Ctx.Finish([winner], "<рядок>",
scores: повні очки)`. `timeline[i]` — за НОМЕРАМИ місць (`timeline[i][seat]`, на порожніх місцях нулі), не за
порядком `players`. `stolen` — скільки разів крав сам, `robbed` — скільки разів крали в нього (звання «Улюбленець
Кармелюка»). `rolls` і `robbed` лежать у знімку ядра (`KhCoreSnap`) — переживають перезапуск. «Ще раз» — нова карта (для `random`), новий перший гравець.

## 10. API 3D-сцени (`web/games/khutory/scene.js`, ES-модуль) — той самий у пласкої карти `board2d.js`

```js
import { createScene } from '/games/khutory/scene.js';      // або createBoard2d з board2d.js
const sc = await createScene(host, {
  onPick(kind, id) {},        // kind: 'v' | 'e' | 'h' — клік/дотик по ПІДСВІЧЕНОМУ місцю
  onHover(kind, id) {},       // kind/id або (null, null) — для підказки «Хата тут дасть…»
  quality: 'high' | 'low',    // low: без тіней і фонової анімації, pixelRatio ≤ 1
  reducedMotion: false,       // true — без польотів і фонової анімації (кидок — миттєвий)
});
sc.setBoard(view.board);              // перебудувати поле, лише якщо змінився board.id
sc.setState(view);                    // фігури, Кармелюк, кольори гравців (players[].color); ідемпотентно
sc.setLegal({ kind, v, e, h });       // kind: 'town'|'city'|'road'|'robber'|null; підсвітити й робити клікабельними ЛИШЕ ці
await sc.roll(a, b);                  // кидок двох кубиків (≤ 1,2 с), закінчується рівно на a і b
await sc.produce(gains);              // gains з події roll: жетони ресурсів злітають із гексів (≤ 1 с)
sc.pop(kind, id);                     // «вистрибнула» нова фігура (build)
sc.screenPos(kind, id);               // { x, y } у пікселях host — для HTML-підказок над полем
sc.glowHexes(ids);                    // ids: number[] | null — м'яко підсвітити гекси («показ», БЕЗ клікабельності; null/[] — зняти).
                                      // Незалежне від setLegal (можуть бути разом); переживає setBoard тієї ж карти
sc.resetView();  sc.resize();  sc.dispose();
```

Сцена не знає правил і не шле дій — лише малює й повідомляє про кліки. Помилка WebGL → `createScene` кидає виняток,
картка переходить на `board2d.js`. HTML-накладки картки над полем (зірки «Глек радить», бейджі Кармелюка, бульбашки
чужих ходів) ставляться через `screenPos` щокадру, поки вони є, — пишеться лише `transform`/атрибут і лише коли змінився
(innerHTML SVG-накладки щокадру Chrome над WebGL не встигав малювати).

## 11. Вигляд 3D («дерев'яна настолка»)

Lo-poly, пласке затінення, тепле світло, лише процедурна геометрія (жодних файлів моделей/текстур). three.js —
`/static/vendor/three-0.186.1/three.module.js`.

- **Гекси** — товсті плитки (висота ~0,18) з фаскою, кольори з `TERRAIN_COLOR`, на кожній — «жителі»:
  ліс — 4–6 дубів/смерек (гойдаються); пасовище — 2–3 вівці (повільно бродять) і тин; лан — ряди колосків (хвиля);
  глинище — яма з глиною, піч-гончарня з димком і 2 глечики; гори — 2–3 вершини зі сніговими шапками, вхід у копальню;
  Дике поле — курган і кам'яна баба.
- **Жетони чисел** — дерев'яні кружальця, число, «крапки» (`PIPS`); 6 і 8 — червоні.
- **Море** — шестикутний «острів» води довкола з легкою хвилею; **пристані** — місток із човником і табличкою курсу
  (2:1 — колір ресурсу, 3:1 — «3:1»), з'єднані з двома вершинами.
- **Тло довкола поля** (28.10, «фон зробити кращим»): спокійне, темне по краях — дошка «вистрибує». Варіант — стала
  `BG_DEFAULT` у `scene.js` (опція `createScene(…, { bg })` перекриває; стенд `dev/scene.html?bg=…`), вигляд —
  `models.BACKDROP`/`backdrop()`; усе процедурне, ≤ +3 draw call до старого:
  `lamp` (**типове**) — темна стільниця з дощок у плямі теплого світла лампи (кольори вершин: повна яскравість під рамкою,
  до країв кадру — майже темрява, туман у колір тла `#0f0905`); `rushnyk` — те саме + рушник-вишиванка за полем (червоно-чорні
  ромби хрестиком, торочки; полотно — CanvasTexture); `khata` — вечірня хата: темніше дерево, у верхніх кутах глечик і свічка
  (мерехтить; reducedMotion/low — рівно), теплий відблиск на стільниці; `sea` — море до обрію, поле — острів без рамки,
  кольори води біля поля — ті самі, що в морі поля (без шва), серпанок у колір тла; `planks` — стара світла підлога («було»).
  Пласка карта (`board2d.js`) — тло SVG у тон: радіальний градієнт темного дерева (для `sea` — синій), `opts.bg` той самий.
- **Фігури в кольорі гравця** (`SEAT_COLOR`): хата — білені стіни, дах кольору гравця; містечко — більша хата з вітряком або
  банею церкви; шлях — дошка-смуга вздовж ребра. Дах має темний кант по стрісі; у «білих» (`SEAT_LIGHT`) дах і шляхи
  кремові `#e6d6b0` — темніші за білені стіни. **Знак гравця** — прапорець на гребені хати/містечка з табличкою-фігурою
  `SEAT_SHAPE` (●▲■◆ = індекс `players[].color`) у кольорі гравця з темним кантом; табличка повертається до камери.
  Пласка карта — те саме: прапорець-фігура над дахом.
- **Кармелюк** — темна постать у шапці на гексі; пересування — стрибок дугою.
- **Кубики** — два 3D-кубики котяться по столу біля поля й зупиняються на заданих гранях (у кадрі: підтягуються до центру,
  якщо за рамкою їх не видно).
- **Підсвітка законних місць** (khutory-look.md §3, однаково в 3D і 2D): колір, якого нема на полі, — золото `#ffd23f` з
  темним кантом `#2a1a00` і м'яким світінням під ним. Вершини — пульсуючі золоті кільця; ребра — золота стрічка над плиткою
  з білими «мурашками», що біжать; гекси (Кармелюк) — золота обвідка. Під курсором — збільшення. Клік лише по них
  (великий хітбокс для дотику). `glowHexes` — окремий «показ»: м'яка золота заливка гекса з яскравішим краєм (адитивно),
  дихає; reducedMotion — без руху мурашок і дихання.
- **Камера**: стартова — впритул до суші й табличок пристаней (усі вершини суші + габарит табличок, межа 0,955 від краю
  кадру): кути моря й рамки можна обрізати, поле — на всю рамку; поки поля нема — шестикутник R = 5,2 (вузька — 5,1). Нахил
  залежить від рамки: ≥ 1,45 — 50°, ≤ 0,9 (телефон стоячи) — 36°, між ними плавно (майже квадратна рамка без смуг стільниці).
  Перспектива, обертання мишею у межах (полярний 35–70°, азимут ±70°), наближення 0,65–1,6,
  згасання руху; подвійний клік / подвійний дотик по порожньому — `resetView`. Поле **не забирає прокрутку сторінки**:
  колесо над полем гортає сторінку (поверх поля на 1,5 с — «Ctrl + коліщатко — наблизити», не частіше раз на 5 с),
  наближення — Ctrl/⌘ + колесо і щипок тачпада. Дотик (`touch-action: pan-y`): один палець угору-вниз гортає сторінку,
  убік — азимут, тицяння — вибір; два пальці — щипок = наближення, ведення = зсув, поворот = азимут. Раз за сесію,
  коли палець пішов у прокрутку, — «Двома пальцями — крутити й наближати». Рішення жестів — `khutory/gestures.js`.
  Пласка карта (board2d) жестів не має: `touch-action: manipulation`, колесо гортає сторінку.
- **Перф**: інстансинг однакових мешів (прапорці — по InstancedMesh на фігуру, без тіней; підсвітка — стрічка + світіння +
  мурашки), ≤ 150 draw call (стенд `main` 1280×800, high: 42 без підсвітки, 45 зі шляхами; було 38/39; тло: lamp/sea 42,
  rushnyk 43, khata 45), тіні лише від сонця (low — без), 60 к/с на ноутбуці з
  вбудованою графікою; прихована вкладка — rAF стоп; `dispose` прибирає все (геометрії, матеріали, слухачі).

## 12. Картка столу (`web/games/khutory.js` + `.css`) — що бачить гравець

- **Розкладка** (khutory-look.md §7; від ширини КАРТКИ — container query `khu`):
  - **ПК** (≥ 700 px): плашки гравців липнуть під шапкою сайту (`top: --gtop-h`); поле ліворуч на висоту екрана
    (`--gfit-h` каркаса − смуга плашок; стеля — ширина поля × 1,12); праворуч колонка тієї ж висоти (своя прокрутка, без
    прокрутки в прокрутці): «що зараз» → панель ходу (кубики, будівлі — у широкій колонці ≥ 330 px в один ряд, банк, торг,
    «Завершити») → **рука одразу під кнопками** (5 ресурсів в один ряд, грамоти — по три) → смуга чисел → вкладки
    **«🤝 Торг · 📜 Журнал · ❔ Правила»** (решта висоти; торг = панель «Даю ⇄ Хочу» + список пропозицій). Вкладка: обрана
    вручну (`st.tab`) — та; інакше торг відкрито чи є пропозиції — Торг, розстановка — Правила, решта — Журнал; на «Торг» —
    значок кількості (червоний — чекають моєї відповіді). «Торгувати» відкриває вкладку й гортає колонку до неї.
  - **Планшет стоячи** (портретний екран, картка 700–859 px): поле на всю ширину, колонка — під ним звичайним потоком.
  - **Телефон** (< 700 px): плашки 2×2 у три низькі рядки (нік і ⭐ — «з N» лише на своїй; карти й грамоти; нагороди) →
    поле (висота = місце між шапкою й липким низом мінус плашки й «що зараз») → «що зараз» → панель ходу (ціни, банк,
    «обміняй і будуй») → смуга чисел → вкладки. Знизу липнуть (над `--gdock-h`: вкладки сайту, міні-плеєр, «💬 Стіл»)
    **рука стрічкою** і **панель дій** `.khu-bar`: 🎲 Кинути кубики / 🃏 Скинути / 🛤 · 🏠 · 🏛 · 📜 · 🤝 Торг · ➡ Завершити
    (≥ 48 px; ті самі `data-a`, що й у панелі ходу; у чужий хід — «🤝 Зустрічна»; нема дій — схована). Шторка вхідної
    пропозиції — над панеллю, поверх руки. Висоти плашок, руки й панелі JS пише в `--khu-plh/--khu-handh/--khu-barh`.
  - Підсумок (`over`) — на всю ширину над полем. Пад (Steam Deck): кільце фокуса йде за геометрією — колонка зверху вниз
    у тому ж порядку.
- **Гравці** згори: колір + фігура ●▲■◆ на аватарці (світлі — темний текст і кант), «⭐ 4 з 8» зі смужкою, «9 карт»
  (понад 7 — 🥷), «2 грамоти», «🛤 3/7» і «⚔ 1/3» (скільки є / скільки треба до нагороди; за крок — золото; власник —
  «Шлях +2»), пристані ⚓. Дотик по значку — поповер-пояснення. Таймер: дуга + смужка на всю ширину плашки того, хто
  думає; останні 10 с — червона рамка пульсує, секунди великим (тік — лише зі ввімкненим звуком). Телефон — сітка 2×2.
- **Смуга чисел** під панеллю ходу (`rolls`, борд, мої хати): 2…12 з крапками ймовірності й тим, що дасть МЕНІ
  (×2 за містечко, Кармелюк — не родить), 7 — 🥷; дотик — `scene.glowHexes(ids)`; «Останні кидки»; «за кидок
  тобі в середньому ≈ N карти». Згортається «🎲 ▴/▾» (пам'ять `kh.nums`), на телефоні прокручується вбік.
- **Поле** посередині (3D або 2D; перемикач «🧊 3D / 🗺 Пласка» в куті, пам'ять у localStorage; WebGL упав — сама 2D).
- **Панель ходу** праворуч (на телефоні — знизу): кубики й «Кинути», кнопки Хата/Шлях/Містечко/Грамота з ціною
  (кружечки ресурсів) і причиною з `me.why`, «Торгувати», «Завершити хід». Натиснув «Хата» — сцена підсвічує
  `me.spots.town`; клік — `act('town', {v})`. Esc/повторний натиск — скасувати вибір.
- **Підказка** при наведенні на підсвічену вершину: «Хата тут дасть: ліс 4 · вовна 5 · 11 %» (сума `PIPS`/36).
  У розстановці — 3 найкращі вершини позначено «Глек радить».
- **Рука** знизу: 5 карт ресурсів із числами (нові — пульсують), грамоти (тиц — пояснення й «▶ Зіграти», свіжа — сіра з причиною).
- **Торгівля**: панель «Даю ⇄ Хочу» (+/− на кожен ресурс), «Усім» / конкретному. **Банк** — завжди в панелі ходу
  (у свій хід, `main`): рядок чипів «4🪵→1» з найкращим курсом (`me.rates`, ⚓ — пристань; сірий, якщо мало); дотик →
  «за 4🪵 бери:» 4 ресурси й «×1/×2/×3» (стільки, скільки дозволяє рука) → `bank {give, get, n}`. Сіра будівля, якій
  бракує 1–2 карт і банк це покриває (`hud-calc.bankFix`, лише надлишок понад ціну), має під собою «🔁 3🌾→🧶 і будуй»:
  1–2 дії `bank` по черзі, тоді — вибір місця (для грамоти — лише обмін). Список пропозицій — у правій колонці
  («дає 1 глину · хоче 1 вовну» — знахідний відмінок); у поточного — хто прийняв, «Обміняти з …»; усі адресати відмовили —
  «🙅 Усі відмовились · ✏ Змінити (cancel + та сама в «Торгувати») · 🗑 Прибрати · 🏦 У банк» (cancel + чип банку).
  Хід Глека: «🤖 Зараз хід Глека: на його пропозицію можна відповісти, а свою запропонувати — у свій хід» (якщо він не
  пропонує обмін мені).
- **Вхідна пропозиція** (чекає МОЄЇ відповіді: від поточного мені/усім, ще не відповів, або зустрічна мені в мій хід —
  `hud-calc.incomingOffers`): ПК — картка в лівому нижньому куті поля, телефон — шторка `sticky` знизу поверх руки
  (≤ 35 % висоти). «🔔 ● Smaug пропонує обмін тобі», «отримаєш 🌾 1 ⇄ віддаси 🪵 1», «у тебе: 🪵 3 → 2», кнопки
  ✅ Згоден (`answer ok`) / ❌ Ні (`answer !ok`) / ↩ Інакше (зустрічна в «Торгувати»); на зустрічну — 🤝 Обміняти (`deal`).
  Смужка й секунди — до власного строку пропозиції `o.until` (Глек чекає до 10 с) або до `deadline`, що
  ближче (не від `botIn` — то найближчий крок будь-якого Глека). Кілька — найновіша + «ще N ▸»; «▾ пізніше» згортає в смужку. Значок кількості — на «🤝 Торгувати».
- **Увага без звуку**: на «твій хід» (`me.must` чи мій `main`/`road2`) і нову вхідну — `navigator.vibrate` (не частіше
  раза на 5 с); вкладка у фоні — заголовок мигає «🎲 Твій хід — Хутори» / «🤝 Тобі пропонують обмін — Хутори» /
  «🃏 Скинь карти — Хутори» (назву повертає, щойно вкладка видна; статичне «🎲 Твій хід ·» ставить ще й app.js);
  раз (`kh.sndAsk` у localStorage) — «🔊 Увімкнути звук гри? Так / Ні, тихо» у куті поля (висить ≤ 20 с).
- **Сімка**: діалог скидання з готовою пропозицією (половина з найчисленніших) — один клік «Скинути», можна поправити.
  Кармелюк — підсвічені гекси з бейджем під кожним (`hud-calc.robberInfo`): кружечки жертв (колір + фігура) і скільки в них
  карт (картка < 400 px — без чисел), «нікого», червоне «⚠ твоя», одне «⭐ Глек радить» (крапки × жертви, лідер). Гекс зі
  своєю хатою не заборонено — перепитуємо «Все одно сюди / Обрати інший». Крадіжка — вибір жертви з кількістю карт.
- **Чужі ходи на полі**: будова — хвиля в кольорі гравця + бульбашка «🏠 владік: нова хата»; Кармелюк — дуга звідки→куди
  й бульбашка «↘ карта від тебе» (червона, якщо в мене); по одній, ≤ 3 с (у черзі — 1,6 с), reducedMotion — без хвилі.
  Стрічка 3 останніх подій ліворуч унизу поля (будова, Кармелюк і крадіжка, обмін «🤝 владік ⇄ банк: 4🪵 → 1⛏️»,
  нагороди), гасне за 6 с. Свої ходи — ні.
- **Грамоти** в руці: тиц — розгортає пояснення (`DEV_HINT`), «▶ Зіграти» — окрема кнопка в розгорнутій (з одного
  дотику не граються). Врожайний рік — вибір 2 ресурсів; Ярмарок — 1 ресурсу; Толока — підсвітка шляхів двічі.
- **❔ Як грати**: кубики, будови, правило відстані, торг і пристані, сімка й Кармелюк, нагороди (Чумацький шлях ≥ 5,
  Найсильніша сотня ≥ 3 козаки, +2 ⭐), грамоти, перемога.
- **Журнал** (`log`) — усі рядки з виду, у вкладці «📜 Журнал»; «❔ Як грати» — вкладка «❔ Правила».
- **Підсумок** (`over`): «🏆 Голова громади», звання (чесний лідер > 0 без нічиєї, ≤ 2 на людину: Чумак року, Отаман,
  Улюбленець Кармелюка, Майстер торгу, Кармелюків побратим, Багатий урожай, Будівничий, Кубики не люблять, Щасливе
  число N), «✨ Твій момент» (коло найбільшого підйому з `timeline`), очки всіх, графік за колами (лінія — за `seat`,
  на кінці фігура), гістограма кубиків, таблиця (з «😿 обкрали»).
- **Боти й час**: `botIn` → `HGames.send('Act', room, 'bot', null)`; минув `deadline` (+0,5 с) → `HGames.send(…'timeout'…)`.
- **status(ctx)**: «Кидай кубики» / «Став хату» / «Скинь 4 карти» / «Хід миколи» тощо.
- Телефон (< 700 px) — див. «Розкладка» вгорі розділу. Дотики — великі цілі (≥ 40 px).
- Звук — хвиля 3 (типово вимкнено).
