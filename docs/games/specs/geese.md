# Порахуй гусей (`geese`) і Гуси дня (`geese-daily`) — хвиля «Вечірка й міні-ігри»

За мотивами Animal Arithmetic. Через двір біжить парад живності, потім Дядько Глек питає «скільки?». Хто точніше (і
трохи швидше) — бере очки. Бриф з рішеннями користувача — `D:/or-wt/_party/games/geese.md`.

Файли: `Impl/GeeseParade.cs` (генератор параду й питання, чистий), `Impl/Geese.cs` (`GeeseBase` — правила й види,
`Geese` — стіл і вечірка, `GeeseBot`), `Impl/GeeseDaily.cs` (`GeeseDaily`, таблиця дня `GeeseDailyBoard`, `GeeseSetup`).
Тести — `tests/Hlechyky.Tests/Games/GeeseTests.cs`. Клієнт — `web/games/geese.js` (+ `.css`), спільний для обох Id.

## 1. GameInfo
- `geese` — «Порахуй гусей», **Party**, 1–8, `TickMs 100`, `Start: ByHost`, опція `botlvl` (`LiveBots.LevelOption`).
  Можна й самому (без бота); «🤖 + бот» — двоє ботів на перших вільних місцях. Не `Hidden` (вид у всіх однаковий,
  крім `mine`/`recap` — див. §4).
- `geese-daily` — «Гуси дня», **Solo**, 1, `TickMs 100`, `Immediate`, `Private, Persistent, Hidden`, `IDailyGame`,
  `Client: "geese"`. Ключ кімнати `daily:geese-daily:<день>:<нік>`.

## 2. Правила
**Раунд:** `ready` → `parade` → `answer` → `reveal`.
| фаза | стіл | вечірка | день |
|---|---|---|---|
| `ready` («готуйсь») | 4 с з питанням / 3 с без | 3,5 / 3 с | як стіл |
| `parade` | 10–15 с (`10000 + 833·рівень`) | 8 / 8,5 / 9 с | як стіл |
| `answer` | 10 с, кінчається раніше, коли відповіли всі | 8 с | 10 с |
| `reveal` | `parade.ms / 2,5 + 2,5 с` | `… + 2 с` | як стіл |

- **Питання до чи після параду** (рішення користувача): раунди 1–3 — питання видно вже в `ready` і на параді;
  з 4-го — лише з `answer` (у `ready`/`parade` замість нього `note` «Дивись уважно — питання буде потім»).
  Вечірка: 1-й раунд — до, 2–3 — після.
- **Партія:** стіл — 7 раундів, рівні 0…6; вечірка — 3 раунди, рівні 1, 2, 4; день — 5 раундів, рівні 0, 2, 3, 5, 6.
- **Рівень** (0…6): тварин `8 + 22·рівень/6` (±1, межі 8–30); доріжок 1 (0–1), 2 (2–3), 3 (4–6); видів 3 + рівень/2
  (до 6); з рівня 2 частина біжить ліворуч (30 %, з рівня 4 — 50 %); з рівня 3 — зграї (3–5 одного виду разом) і
  тин/віз (1, з рівня 5 — 2), за якими видно лише частину тварини; швидкість `0,20 + 0,035·рівень` ширин двору/с
  (× темп виду: кіт 1,25, коза 1,1, курка 1, гуска 0,95, порося 0,9, качка 0,85; ×0,9–1,1).
- **Живність:** `goose` гуска 🪿, `hen` курка 🐔, `duck` качка 🦆, `goat` коза 🐐, `pig` порося 🐖, `cat` кіт 🐈.
  **Прикмети** (2–3 на партію, ~35 % тварин свого виду): `hustka` коза в хустці, `hlechyk` гусак із глечиком на
  голові, `chorna` чорна курка, `bant` порося з бантиком, `rudyi` рудий кіт. Тварина з прикметою — та сама тварина:
  у «Скільки кіз?» коза в хустці рахується.
- **Питання** (`q.type`): `count` «Скільки курей пробігло двором?» (вид, якого ≥ 2), `sum` «Гусей і качок разом —
  скільки?» (з рівня 1), `most` «Кого було найбільше?» — вибір з 2–4 варіантів, найбільший завжди один (з рівня 1),
  `trait` «Скільки кіз у хустці?» (з рівня 2, ≥ 1), `dir` «Скільки тварин бігло ліворуч?» (з рівня 2, ≥ 1).
  Один тип двічі поспіль не буває.
- **Відповідь:** одна, остаточна (число 0–60 або номер варіанта). **Очки:** точно — 3, мимо на одну — 1 (вибір —
  лише точно), найшвидшому з точних +1 (рівні за мс — усім), якщо в партії грає двоє й більше (з ботами теж).
- **Кінець:** переможці — найбільше очок; усі по 0 — нічия. Журнал: «Порахуй гусей: Оля 14 : Петро 9».
- **Вихід:** за столом той, хто пішов, більше не рахується (на його відповідь не чекаємо); пішли всі люди — кінець
  без переможців. Новий гравець посеред партії — глядач («Ти тут не граєш»).

## 3. Дії
| action | payload | коли |
|---|---|---|
| `answer` | `{n: 0..60}` — число; `{c: індекс}` — для `q.opts` | лише `answer`, своє місце, раз |
| `bot` (`LiveBots.Toggle`) | `{on: bool}` | стіл, лобі або `done`, господар сам за столом; у вечірці й «Гусях дня» — відмова |

Відмови (тост): «Спершу подивись парад», «Відповідати вже пізно», «Відповідь уже є», «Число від 0 до 60», «Обери
одного з варіантів», «Ти тут не граєш». Нелегальне вид не міняє (тест).

## 4. Вид (`View(seat)`) — для клієнта
Одиниці: час — **мс**, координати — **частки ширини двору** (0 — лівий край, 1 — правий), доріжки згори вниз.
```
{
  ph: 'lobby'|'ready'|'parade'|'answer'|'reveal'|'done',
  round: 1..rounds (0 у лобі), rounds: 7|3|5, level: 0..6,
  el: мс від початку фази (на мить побудови виду), left: мс до кінця фази, dur: довжина фази, мс,
  pre: питання цього раунду показують до параду,
  note: 'Дивись уважно — питання буде потім' | null   (ready/parade раунду «після»),
  q: null | { type, text, kinds: [id], trait: id|null, opts: null|[{k, name, emo}], max: 60 },
       // видно: pre — з ready; інакше — з answer
  parade: null | {          // з parade (у ready — null), лишається до кінця раунду
    seed,                   // для косметики (хитання, пір'я, пил) — НЕ для складу параду
    ms, m: 0.08, lanes: 1..3, rx: 2.5,   // rx — у скільки разів швидше повтор на reveal
    animals: [{k, tr: id|null, l: доріжка, d: 1|-1, t0: мс, v: ширин/с, y: −0.25..0.25 (зсув у доріжці), f: зграя|-1}],
    covers:  [{kind: 'tyn'|'viz', l, x0, x1}]   // малювати ПОПЕРЕДУ тварин своєї доріжки, закриває нижню частину
  },
  players: [місця, що грають], bot: [місця ботів], scores: [очки кожного місця 0..7 (вечірка — 0..N−1)],
  answered: [місця, що вже відповіли] (лише в answer), mine: моє число/варіант | null (лише в answer, лише собі),
  reveal: null | { answer, kind: id|null (для most), hits: [індекси animals-відповіді],
                   rows: [{s, a: число|варіант|null, pts, fast}] },   // reveal і done поточного раунду
  recap: null | [{q, answer, mine, pts}] (done, лише своє місце),
  winners: [місця] | null (done),
  botOffer, botWanted, botLvl, party: bool,
  daily: null | {day, no, max: 15, board: null|[{nick, points, marks}], place, players, share}   // «Гуси дня»
}
```
**Рух тварини:** `p = (t − t0)/1000 · v`, `x = d > 0 ? −m + p : 1 + m − p`; видно, поки `−m ≤ x ≤ 1 + m`. Кожна
тварина гарантовано перебігає двір до `ms`. На `reveal` клієнт крутить той самий парад з `t = (el·rx)` (до `ms`), тварин
з `hits` підсвічує й веде лічильник «1, 2, 3…» у міру їхньої появи; далі — таблиця `rows`.

**Синхронність (≤ 200 мс):** парад не з локального годинника: клієнт на кожен вид/кадр ставить
`phaseStart = performance.now() − el` (зсув лише вперед-назад на кілька десятків мс — згладжувати). Сервер шле вид
на кожну зміну фази й на кожну відповідь (`TickResult.Both`).

**Кадр (`Frame`)**: `{ph, round, el, left, answered}` — малий, для підтягування годинника; повний парад — лише у виді.
Кадр і вид бачать усі — нічого таємного: склад параду не таємниця (його всі бачать на екрані), правильна відповідь
з'являється лише в `reveal`, а питання раунду «після» — лише з `answer`. Чужі числа — лише в `reveal.rows`.

## 5. Бот (`GeeseBot.Plan`)
Думає раз на початку `answer` (`Ctx.Rng`), відповідає тим самим шляхом, що людина, із затримкою:
| рівень | затримка | число: точно | інакше | вибір: правильно |
|---|---|---|---|---|
| легкий | 4–7,5 с | 25 % | ±1…3 | 45 % |
| звичайний | 2,5–6 с | 50 % | ±1 (80 %), ±2 | 70 % |
| сильний | 1,5–4,5 с | 75 % | ±1 | 88 % |
На рівні параду ≥ 4 ймовірності −10 п. п. Затримка ≤ вікно відповіді − 300 мс. Бот на місці людини, що сіла, не грає.

## 6. Режим вечірки (`IPartyMinigame`)
`party=1`, `bots`, `botlvl` — у `Configure`. 3 раунди (1 — до, 2–3 — після), ~60 с, коли всі відповідають, ~75 с,
коли ніхто. `PartyCapMs = 100 000`. Гравців 2–8. **Scores** = сума очок кожного місця 0..N−1; `Finish(winners, log,
scores)` після 3-го показу. Без бота-кнопки, ачівок, `Award/Score`; Глек у вечірці мовчить. Людина, що відпала посеред
— просто не відповідає (на неї не чекають). `Howto`: «Рахуй живність, що біжить двором, і відповідай…».

## 7. «Гуси дня»
Сід — `Days.Seed("geese", день)`: той самий парад і питання для всіх за київську добу. Одна спроба; «Ще раз» на
зіграному дні — лише підсумок. Кінець: `Score(0, 0, 1)` (щоденний каркас: «зіграно»), `Award daily:geese-daily`,
рядок у таблицю дня `geese_daily` (`GeeseDailyBoard`, очки в «☀ Сьогодні» через `IDailyPoints`), Журнал «Гуси дня:
Оля — 12 з 15 🎯🎯🟨🎯⬛». `Save/Load`: день, раунд, очки, смужка; недограний день — з «готуйсь» того раунду, де
зупинився (зіграні раунди лишаються зіграними).

## 8. Ачівки (лише стіл, від двох людей, без ботів)
- `geese-shepherd` «Пастух» — усі 7 раундів точно (`ach:` з гри).
- `geese-eagle` «Орлине око» — точне число в 7-му (рівень 6, найшвидшому) параді, якщо там питання-число.
- `geese-days5` «Гуси дня» — 5 днів «Гусей дня» поспіль (`Achievements.OnDaily`, серія каркаса).

## 9. Дядько Глек (`Ctx.Say`, рідко)
На старті столу від двох людей — 1 з 2; на показі — усі мимо (1 з 3), один точний серед ≥ 3 (1 з 3), питання про
прикмету (1 з 4), разом не більше двох на показах; у кінці — переможцю (1 з 2). У вечірці й «Гусях дня» — мовчить.

## 10. Клієнт (наступний етап)
Модуль `geese` з `added: '2026-10-06'`, `gico` 16×16. Двір на canvas (`ui.canvas`, розмір — від `root`), тварини —
великі впізнавані силуети/емодзі, прикмети — помітні (хустка, глечик). Відповідь — великі цифри й −/+ (≥ 44 px), свої
кнопки, не системна клавіатура; вибір — 2–4 великі кнопки з емодзі; клавіші: цифри, ↑/↓ (±1), Enter; пад: ↑/↓ ±1,
←/→ ±5 або вибір, A — відповісти. Показ — повтор ×2,5 з підсвіткою `hits` і лічильником. Вбудовування —
`HGames.embed` (нічого поза `ctx`/`root`, усе прибрати в `unmount`).
