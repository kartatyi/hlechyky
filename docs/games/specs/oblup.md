# «Як облупленого» (`oblup`)

Компанійська гра «чи знаєш ти друзів». Основа — настолка Cross the Line (Gray Matters Games, рілс 01.11.2026):
одного питають, де він себе поставить між двома крайнощами, решта вгадує, де він стане. Наша фішка, як у них, —
рамки різної ширини: широка — майже напевно влучиш, але дешево; вузька — ризик і багато очок. Назва — з приказки
«знати як облупленого».

Користувач 01.11: «потрібно зробити таку гру… вирішуй усе сам». Усі рішення нижче ухвалені мною без питань.

## 1. Правила

- Стіл 2–8, `Party`, старт господарем. Ботів нема: вгадувати бота — не про друзів.
- Партія — кола: кожен за столом по черзі стає **«в центрі»** (герой раунду). Опція «Кіл»: `auto` (до 4 гравців —
  2 кола, від 5 — 1), 1, 2, 3.
- Раунд:
  1. **Пауза** 3 с: «У центрі — Оля».
  2. **Вибір** (15 с): герой бачить два питання й бере одне (не встиг — перше). Решта бачить «Оля обирає питання…».
  3. **Ставки** (опція «Час» 30/45/60 с, типово 45): питання з двома крайнощами («Ананаси на піці»: «злочин» ↔
     «шедевр»). Герой таємно ставить себе на шкалу 0–100; решта ставить рамку — центр і ширину. До кінця часу можна
     пересувати. Усі поставили — фаза кінчається одразу.
  4. **Риска** (8 с): правда героя падає червоною рискою крізь доріжки всіх гравців; рамка, яку риска перетнула, —
     влучання.
- Рамки (ширина в одиницях шкали → очки): **широка 30 → 2**, **середня 18 → 3**, **вузька 8 → 6**. Влучання —
  риска всередині рамки, межі включно. **🎯 В яблучко**: риска за ±1 від центру рамки — ще +1.
  Розрахунок рівноваги (похибка вгадувача нормальна σ): σ = 15 (чужа людина) — усі рамки ≈ 1,3 очка в середньому,
  σ = 8 — середня й вузька ≈ 2,2–2,3, σ = 5 (знаєш як облупленого) — вузька 3,4 проти 2,0 у широкої. Тобто ризик
  окупається саме тоді, коли справді знаєш людину.
- Герой у своєму раунді очок не бере: кожен однаково разів буває в центрі. Герой не поставив себе — раунд без очок.
- «⚖ Фора» — як скрізь (`Handicap`). Черепки — за кожні 5 очок партії (як «Скільки?»), понад звичайну виплату каркаса.
- Хтось пішов: його рамки й черга в центрі зникають; пішов герой посеред раунду — раунд без очок. Менше двох — кінець.

## 2. Питання

- Банк `data/oblup/questions.json`: `{ id, q, l, r, tags[], spicy? }`. `q` — до 90 знаків, полюси — до 32. Питання
  звернене до героя на «ти», полюси — короткі відповіді, що читаються з обох боків («Ти й будильник» — «встаю з
  першого» ↔ «десять разів відкладаю»). Без політики й війни, без образ; «🌶 Гостре» (`spicy`) — лише з опцією.
- Пам'ять баченого — спільна `game_seen` (ключ гри `oblup`): у вибір ідуть ті, яких ніхто за столом не бачив або
  бачив найдавніше. Бачив = питання показали героєві у виборі (обидва варіанти).
- **✍ Свої питання**: у лобі й посеред партії кожен може дописати до 3 своїх (питання + два полюси). Вони йдуть у
  вибір першими (по одному в парі), автор у центрі своє не отримує. Живуть, доки стоїть стіл.

## 3. Кінець і підсумок

- Перемога — найбільше очок (нічия — кілька переможців; усі нулі — нічия без переможців).
- Підсумок: усі раунди (питання, герой, де стояв, скільки влучило) і **«Хто кого знає»** — для кожного героя той,
  хто набрав на ньому найбільше очок; плюс «📖 Відкрита книга» (на кому влучали найчастіше) і «🎭 Темна конячка»
  (на кому — найрідше), якщо є з чого вибирати.
- Дядько Глек коментує кожну риску рядком на картці (лише називний відмінок у ніках).

## 4. Протокол

Дії: `pick {i}` (0/1, лише герой у виборі), `place {pos, size}` (герой — лише `pos`; `size` = `w|m|n`),
`mine {q, l, r}` (своє питання; порожнє `q` з `id` — прибрати своє `{del: id}`).

Вид (`Hidden`, свій для кожного місця):
```
{ phase: 'between'|'pick'|'guess'|'reveal'|'done', round, of, hero, endsAt, seconds,
  choices: [{q,l,r,own}] | null        // лише герою у виборі
  q: {q,l,r,own} | null                 // з фази ставок
  done: bool[]                          // хто вже поставив (герой теж)
  my: {pos, size} | null                // своє, до розкриття
  sizes: [{key, width, points}]         // рамки — клієнт малює з цього
  reveal: {pos, say, rows:[{seat,pos,size,hit,bull,points}]} | null
  scores, handicap, result, recap, mine: {list:[{id,q,l,r}], max, total}, laps }
```
Кадр (`Frame`): `{round, phase, endsAt, done, scores}` — без прихованого.

## 5. Клієнт

`web/games/oblup.js` + `.css`. Шкала — градієнт від полюса до полюса з підписами по краях; рамка/мітка тягнеться
пальцем чи мишею, клавіші ←/→ (Shift — по 5, затиснута — їде), ↑/↓ чи R — ширина рамки, Enter — «Ставлю». Цифри
1–4 НЕ чіпаємо: це гарячі клавіші розділів сайту (вибір питання перекидав би на «Ефір»). Вибір питання — клік чи ←/→ і
Enter. Пад: стік — по шкалі, A — поставити, X — інша рамка. Рамку, що стоїть, але не відіслана, клієнт відсилає сам
за 1,3 с до кінця ставок. Розкриття — доріжки гравців одна під одною (як у коробці настолки) і червона риска, що
з'їжджає згори вниз; влучні рамки світяться зеленим, 🎯 — золотим. «Хто в центрі» позначено 📍 (🎯 — лише яблучко).

## 6. Що лишилось на потім

- «Глек пам'ятає»: зберігати, де людина ставила себе на те саме питання раніше, і питати «а минулого разу ти був
  тут — що сталось?». Потрібна таблиця в базі; у v1 не робив.
- Таблиця «хто кого знає» між партіями (з `game_results` чи своєї таблиці).
