# Морський бій (`battleship`) — пункт 15

**Info:** `Id="battleship"`, `Title="Морський бій"`, `Accusative="морський бій"`, `Group=Board`, 2/2,
`Hidden=true`, `Rated=true`, `Hint="Розстав кораблі, стріляй по чужому полю. Влучив — стріляєш ще"`.
`SeatName`: «синій»/«червоний» (кольори — `--accent` не треба: чіп-класи `x`/`o` як у каркасі).

## Правила

- Поле 10×10 (a–k без «й»? ні — колонки латиницею a–j, рядки 1–10; у виді індекс 0..99).
- Кораблі: 1×4, 2×3, 3×2, 4×1 (класика). Не торкаються навіть кутами.
- **Фаза розстановки.** Обидва гравці розставляють одночасно (гра стартує в фазі `placing`). Дії:
  `place` з повною розстановкою (валідність перевіряє сервер), `random` (сервер сам розставляє з `Ctx.Rng`),
  `ready`. Коли обидва `ready` → фаза `battle`, першим стріляє місце 0 (у рематчі — обертання каркасом).
  Таймер розстановки — 120 с (за `Ctx.Clock`; перевіряти в `Act` і в `Tick` — гра має `TickMs=1000`): хто не
  готовий — отримує випадкову розстановку автоматично.
- **Бій.** `shoot {cell}`: промах → черга суперника; влучив → стріляєш ще; потопив → ще, клітинки навколо
  корабля позначаються промахами автоматично (у виді). Повторний постріл у відому клітинку — Fail.
- Перемога — усі 10 кораблів суперника потоплені. Вихід — техпоразка.

## Дії

| action | payload |
|---|---|
| `place` | `{ ships: [{ cells: number[] }] }` — 10 кораблів; сервер перевіряє склад, прямолінійність, дотики, межі |
| `random` | — |
| `ready` | — (потрібна валідна розстановка) |
| `shoot` | `{ cell: number }` |

## Вид (`Hidden`)

```ts
{
  phase: 'placing'|'battle'|'done',
  turn: 0|1|null,                     // null у placing
  placeUntil: string|null,            // ISO, кінець таймера розстановки
  me: null | {                        // тільки для сидячого; глядач — null
    ships: number[][],                // мої кораблі
    ready: boolean,
    hits: number[], misses: number[]  // куди суперник уже стріляв по мені
  },
  enemy: {                            // моє знання про поле суперника (глядач бачить обидва «enemy»-подання без кораблів)
    hits: number[], misses: number[], sunk: number[][],   // sunk — повні клітинки потоплених
    ready: boolean, left: number      // скільки кораблів ще на плаву
  },
  boards?: [enemyLikeA, enemyLikeB],  // тільки для глядача (seat == null): обидва поля в «enemy»-форматі
  shots: number,                      // усього пострілів у партії
  result: null | { winner: 0|1, shots: [number, number] }
}
```
**Тест на приховування:** у `View(1)` немає `ships` місця 0 ні в якому полі; у `View(null)` — жодних `ships`.

## Клієнт

- Два поля поряд (на вузькому — одне під одним): «Моє» і «Чуже». У `placing`: перетягування зі списку
  кораблів або кнопки «Випадково» + «Готово»; поворот корабля — клік по ньому. У `battle`: клік по «Чужому».
- Влучання — `--clay` крапка, потоплений — заливка `--danger`, промах — маленька крапка `--muted`.
- Анімація «бризки» на промах не обов'язкова.

## Тести (≥ 25)

- Валідатор розстановки: правильна проходить; дотик кутами — Fail; корабель за межами; неправильний склад;
  не прямий корабель.
- `random` 200 разів із різними сідами → усі валідні.
- Таймер: `Tick` після 120 с → неготовим дано випадкове, фаза battle.
- Постріл не в свою чергу; повторний постріл; влучання дає ще хід; потоплення позначає околиці; перемога
  після 20 влучань.
- Приховування у видах; глядач бачить обидва поля без кораблів.
- Виплата: `MinRewardMoves=10`.
