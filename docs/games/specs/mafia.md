# Мафія (`mafia`) — пункт 46

**Info:** `Id="mafia"`, `Title="Мафія"`, `Accusative="мафію"`, `Group=Party`, 4/12, `Start=ByHost`,
`Hidden=true`, `TickMs=1000`, `Rated=false`,
`Hint="Село засинає, прокидається мафія. Уночі — в приваті, удень — суперечки й голосування. Ведучий — Дядько Глек"`.
`SeatName(i)` = `"гравець {i+1}"` (ролі — секрет).

## Ролі (від кількості гравців N)

| N | мафія | комісар | лікар | мирні |
|---|---|---|---|---|
| 4–5 | 1 | 1 | 0 | решта |
| 6–8 | 2 | 1 | 1 | решта |
| 9–12 | 3 | 1 | 1 | решта |

Роздача — `Ctx.Rng`. Мафія знає одна одну.

## Фази (усе за `Ctx.Clock`, перевірка в `Tick`)

1. `intro` (10 с): усі бачать свою роль. Глек: «Село засинає…».
2. `night` (45 с або коли всі нічні дії зроблені):
   - мафія: `kill {seat}` — кожен мафіозі голосує; ціль — більшість, при рівності — перший за часом
     останнього голосу; мафія бачить голоси одна одної і має **нічний чат**: `say {text}` (≤ 200 символів,
     видно лише мафії, зберігається в стані, ≤ 50 рядків);
   - комісар: `check {seat}` → у своєму виді бачить «мафія/не мафія» (накопичується список);
   - лікар: `heal {seat}` — може себе, але не двічі поспіль ту саму людину.
3. `day` (оголошення 5 с + обговорення 90 с): «Уночі не стало X» або «Уночі всі вціліли» (якщо лікар
   врятував). Обговорення — у **загальному чаті Балачок** (це і є фішка: люди сперечаються в звичайному чаті),
   кімната лише показує таймер і список живих.
4. `vote` (45 с): `vote {seat|null}` (null — утриматись), можна міняти до кінця. Голоси **відкриті** в
   реальному часі (класика «пальцем»). Більшість від живих → вигнаний, роль розкривається («Петро був
   мирним»). Рівність/утримання — ніхто не йде.
5. Перевірка перемоги після кожної фази: мафія = 0 → мирні; мафія ≥ живих мирних → мафія.
   `Finish(переможці-місця, "мафія: перемогли мирні (комісар Оля вивела всіх на чисту воду)")`.
   Виплата: каркас (Winners = усі живі й мертві гравці команди-переможця — так, мертві теж отримують).
6. Мертві бачать усе (ролі, нічний чат) і мовчать у кімнаті (у Балачках їм не заборониш — правило честі,
   Глек нагадує «Мертві мовчать»).

Вихід гравця посеред партії — «виїхав із села» (вважається мертвим, роль розкривається); якщо через це
умова перемоги виконана — Finish. Мінімум для продовження — 3 живих, інакше нічия.

## Дядько Глек — ведучий

- Усі системні репліки (`Ctx.Say`) — з банку статичних шаблонів у стилі села (≥ 25 фраз, з підстановками
  ніків). Це база: гра повністю працює без ключа Anthropic.
- Додатково, якщо `DjBrain.FlavorAsync` доступний (WP1; повертає null, коли бот вимкнений/стеля), на початку
  дня Глек може дати **один** LLM-коментар (fire-and-forget, з підказкою «2 речення, не видавай ролей,
  ось що сталось: …»). Не більше 4 викликів на партію. Результат — `Ctx.Say` лише якщо партія ще йде
  (перевірка під замком). Це не має впливати на фази.

## Дії

`kill`, `check`, `heal`, `say` (ніч, мафія), `vote` (день). Кожна перевіряє фазу, живість і роль; інакше
Fail «Зараз не час» / «Це не твоя справа».

## Вид (Hidden)

```ts
{ phase: 'lobby'|'intro'|'night'|'day'|'vote'|'done', day: number, endsAt: string,
  players: [{ seat, nick, alive, role: string|null }],   // role: своя завжди; чужі — мертвим/після кінця/мафії про мафію
  me: { role: 'mafia'|'sheriff'|'doctor'|'civil', alive: boolean } | null,   // глядач — null
  night: { votes: Record<seat, seat>, chat: [{ seat, text }], myCheck: {seat, mafia}[] , healed: seat|null } | null,  // лише для мафії/комісара/лікаря — кожному своє
  dayInfo: { killed: seat|null, saved: boolean } | null,
  votes: Record<seat, seat|null>,        // відкриті голоси в фазі vote
  log: string[],                         // публічна хроніка («День 2: вигнали Петра (мирний)»)
  result: null | { winners: number[], team: 'mafia'|'civil'|'draw' } }
```
Тести на приховування: мирний не бачить ролей інших живих; комісар не бачить ролі, крім перевірених;
глядач бачить лише `players` без ролей і `log`.

## Ачівки

- `mafia-win` («Мафіозі») — перемога за мафію; `sheriff` («Комісар») — комісар перевірив і справді знайшов
  мафію. Ролі знає лише сама гра, тому вона й просить: `Ctx.Award(seat, 0, "ach:mafia-win")` і
  `Ctx.Award(seat, 0, "ach:sheriff")` (нуль черепків — їх платить сама ачівка, див. ARCHITECTURE §8).

## Клієнт

- Картка: велика фаза й таймер-дуга, список гравців (мертві перекреслені, ролі коли відомі), моя роль
  великим чіпом. Ніч: мафії — кнопки «Вбити» біля живих + нічний чат; комісару — «Перевірити»; лікарю —
  «Врятувати». День: напис «Сперечайтесь у Балачках». Голосування: кнопки «Вигнати» біля кожного, живі голоси.
- Нагадування «Обговорення в Балачках» з кнопкою переходу на вкладку чату (на телефоні).

## Тести (≥ 40)

- Роздача ролей для N=4..12 за таблицею; мафія знає мафію.
- Ніч: kill більшістю; рівність; лікар рятує; лікар двічі поспіль одну — Fail; комісар бачить результат
  тільки у своєму виді.
- День/голосування: більшість, рівність, утримання, зміна голосу.
- Перемоги: мафія 0; мафія ≥ мирних; вихід гравця; < 3 живих → нічия.
- Фази за FakeClock, дострокове завершення ночі, коли всі діяли.
- Приховування у видах (5 окремих тестів).
- Виплата: Winners включають мертвих членів команди.
