# Склей глек (`sklei`)

За мотивами Fractured Faces. Картинку розбито на черепки — перетягни кожен на місце й поверни рівно. Хто склав
першим — той вище. Група **Live**, 1–8 гравців (сам — з 🤖 ботом), `TickMs = 100`, старт — господар (`ByHost`).
Сервер: `Impl/Sklei.cs` (гра), `Impl/SkleiCut.cs` (розбивка, картинки), `Impl/SkleiDeck.cs` (колода),
`Impl/SkleiSetup.cs` (DI й ендпоінти). Вбудовані картинки — `web/games/sklei/*.svg`. Тести — `SkleiTests.cs`.

## 1. Правила

- Партія — **3 картинки поспіль** (у вечірці — 1). Картинка: «Готуйсь» 3 с (`ready`) → складання (`go`) → підсумок
  картинки 6 с (`pause`) → наступна; після третьої — `over` і Finish.
- Складання кінчається, коли склали всі, хто ще грає (бот і люди за столом), або за лімітом картинки, або через
  **60 с після першого**, хто склав (що раніше).
- Місця в картинці: хто склав — за часом; далі ті, хто ні, — за кількістю прирослих черепків; рівні — поділене місце.
  Очки за місце: **10 / 7 / 5 / 4 / 3 / 2 / 1 / 0**; хто не склав — половина (цілочисельно) за своїм місцем; нуль
  черепків — 0. Підсумок партії — сума; переможці — люди з найбільшою сумою (> 0; усі по нулях — без переможця).
- Складність (опція `level`):

| key | черепків | повороти | контур-підказка | ліміт картинки |
|---|---|---|---|---|
| `easy` | 9 (3×3) | ні | так | 120 с |
| `normal` | 16 (4×4) | так | так | 180 с |
| `hard` | 25 (5×5) | так | ні | 300 с |
| `master` | 36 (6×6) | так | ні | 420 с |

- **Телефон**: не більше 16 черепків (N ≤ 4) — «важко» й «майстер» на телефоні = 16 без контуру. Клієнт каже про
  пристрій дією `dev`; діє з **наступної** картинки (поточну не перекроюємо). Тож за одним столом у гравців може бути
  різне N — розбивка однакова в усіх з тим самим N (та сама картинка, той самий сід).
- Опція `pics` «Картинки»: `all` (усі: вбудовані 4 : фото 3 : малюнки 2 : свої 2 — вагами серед непорожніх),
  `pots` (вбудовані глеки й візерунки), `photo` (фото «Де це?»), `friends` (малюнки з альбому Піктіонарі), `mine` (свої
  картинки тих, хто сидить за столом). Без повторів у межах партії. Порожній вид (нема фото, малюнків, своїх) —
  вбудована картинка: партія не ламається.
- Поворот — **лише за годинниковою** (тап, колесо в будь-який бік, правий клік — усе +90°): так сервер перевіряє кут за
  кількістю тапів. «Хибний поворот» — черепок покладено після зайвих тапів (`t > потрібно`, тобто зайве коло).

## 2. Дії (`act`)

| дія | payload | коли | що |
|---|---|---|---|
| `put` | `{k, c, r, t}` | `go` | поклав черепок `k` у клітинку `c` з кутом `r` (0..3), натиснувши поворот `t` разів |
| `dev` | `{phone: bool}` | будь-коли | телефон чи ПК (шли на mount і коли зміниться `HGames.ui.coarse()`) |
| `bot` | `{on: bool}` | лобі / `over` | «🤖 + бот» каркаса (`LiveBots.Toggle`) |

`put` приймається лише правильний: `c == k`, `r == 0`, `0 ≤ t ≤ 400`, `(r0[k] + t) % 4 == 0` (без поворотів — `t == 0`),
черепок ще не на місці, гравець не склав. Інакше — відмова (`Fail`, тост), стан не міняється. **Неправильне клієнт не шле**:
черепок, кинутий не туди (чи не тим кутом), просто лишається на столі. Після `put` у `go` вид не шлеться одразу —
приходить з наступного тику (≤ 100 мс). Перший `put`, що склав картинку, — `me.done` у виді.

## 3. Розбивка (`cut`) — як малювати черепки

Одиниця — **cu**, сота частка клітинки: клітинка = 100 cu, картинка = N·100 cu. Черепок `k` = рядок `k / N`, стовпчик
`k % N` (k = row·N + col) — його правильна клітинка `c = k`.

- `v` — зсув вузлів сітки: `(N+1)²` пар `(dx, dy)`; вузол (i — стовпчик 0..N, j — рядок 0..N) → `v[(j·(N+1)+i)·2]`,
  `[...+1]`. Позиція вузла: `(i·100 + dx, j·100 + dy)` cu. Зовнішній край рівний (на краю dx або dy = 0, кути — 0).
  Внутрішні — ±16 cu.
- `eh` — горизонтальні **внутрішні** шви (між рядками; j = 1..N−1, i = 0..N−1): шов іде від вузла (i, j) до (i+1, j);
  дві точки вигину на 1/3 і 2/3 шляху, зсунуті **вниз** (+y) на `eh[((j−1)·N+i)·2]` і `[...+1]` cu (±13).
- `ev` — вертикальні внутрішні шви (i = 1..N−1, j = 0..N−1): від вузла (i, j) до (i, j+1); дві точки на 1/3 і 2/3,
  зсунуті **вправо** (+x) на `ev[((i−1)·N+j)·2]` і `[...+1]` cu.
- Зовнішні сторони черепків — прямі. Контур черепка (row, col): TL → верхній шов → TR → правий шов → BR → нижній шов
  (у зворотний бік) → BL → лівий шов (у зворотний бік). Ламана з 4 відрізків на шов — «як тріснуло»; гладити кривою
  чи ні — смак клієнта, але сусіди мусять малювати той самий шов.
- `tray` — розклад на столі: на черепок `k` трійка `[x, y, r0]`: центр черепка в **проміле** (0..1000) прямокутника
  «стіл», який клієнт кладе де хоче (на ПК — збоку від рамки, на телефоні — під нею), і початковий поворот `r0`
  (0..3 чверті за годинниковою). Черепки розкладено по сітці столу без накладань.
- Магніт (клієнт): черепок відпустили так, що його центр ближче за ~35 % клітинки до центру клітинки `k` у рамці, і
  кут = 0 → шли `put` і «приріс» (анімація); інакше — лежить, де кинули.

## 4. Вид (`View(seat)`) і кадр

Вид (усе публічне, крім `me` — лише своє):

| поле | що |
|---|---|
| `ph` | `lobby` / `ready` / `go` / `pause` / `over` |
| `level`, `rotate`, `hint` | складність; чи є повороти; чи показувати контур-підказку (бліду картинку в рамці) |
| `n` | N **цього гравця** (глядачу — за опцією) |
| `party`, `pics`, `picNo` | режим вечірки; скільки картинок у партії; номер поточної (1..pics) |
| `pic` | `{key, kind, url, title, by}` — `kind`: `svg` / `geo` / `art` / `own`; `by` — автор (малюнок друга, своя), інакше null |
| `cut` | `{n, v, eh, ev, tray}` (§3) для свого N; у лобі null |
| `until`, `leftMs` | кінець фази (ISO) і скільки лишилось мс на мить виду |
| `goAt` | коли почалось складання цієї картинки (ISO) — для свого секундоміра |
| `me` | `{placed: [k…], done: мс|null, bad}` — мої прирослі черепки, за скільки склав, хибних поворотів; не граєш — null |
| `phone` | що сервер думає про мій пристрій |
| `players` | `[{seat, name, bot, placed, of, done, place, pts, total, gone}]` — прогрес усіх (%), місце в картинці, очки за неї й разом |
| `history` | `[{pic, rows: [{seat, place, pts, ms, placed, of}]}]` — підсумки зіграних картинок |
| `winners` | у `over` — переможці |
| `botOffer`, `botWanted`, `botLvl`, `bot` | «🤖 + бот» (як у Понгу) |

Як брати картинку за `kind`:
- `svg`, `geo`, `own` — `url` і є картинка (`<img>`/`drawImage`, квадрат). `geo` — токен «Де це?» на 45 хв.
- `art` — `url` = `/api/games/sklei/art/<id>` → JSON `{id, word, by, z}`; `z` — штрихи як в альбомі Піктіонарі
  (SketchWire, той самий рендер, що в альбомі), малюй у квадрат на білому тлі.

Кадр (`Frame()`, щотику, коли щось змінилось, разом із видом) — лише публічний прогрес:
`{ph, picNo, leftMs, p: [[seat, placed, of, doneMs|-1], …]}`. Ні розкладу, ні чиїхось наборів.

## 5. Бот і соло

«🤖 + бот» — один бот на місці після людини, рівень — опція `botlvl`. Бот кладе **правильний** черепок тим самим
`Place`, що й людина (поворотів рівно скільки треба), раз на «подумати»: легкий 6 с, звичайний 3,5 с, сильний 2 с ×
складність (9 без поворотів ×0,68, 16 ×1, 25 ×1,1, 36 ×1,2) × ±30 %; іноді задивляється (пауза ×2: 15 / 8 / 4 %).
Перший черепок — після «погляду» 0,8–1,4 × «подумати». 16 черепків: сильний ≈ 30–40 с, легкий ≈ 100 с.
Партія з ботом — без нагород і ачівок; переміг бот — `winners []` + «🤖 Бот склеїв швидше»; людина —
«🏆 … перемога над … ботом». Людина встала — партія кінчається.

## 6. Колода, своя картинка, автору +1

- **Своя картинка** — лише акаунт, **400 черепків** (`Economy.TrySpend`). Клієнт обрізає квадрат і стискає до
  ≤ 768×768 JPEG/WebP ≤ 300 КБ (як «Своя фотка» Лавки), `POST /api/games/sklei/pic` з тілом-файлом. Сервер перевіряє
  тип за магічними байтами (JPEG/PNG/WebP), розмір ≤ 300 КБ, сторони 64..768, квадрат (±2 %), до 60 картинок на акаунт,
  ту саму двічі — ні. Спершу файл, потім оплата: не списалось — файл геть. Зберігання — `data/sklei/<хеш>.<ext>` +
  рядок `sklei_pics(id, file, author, author_key, at, bytes, hidden, removed, solved)`.
- Без премодерації: розробник знімає (`POST /api/games/sklei/pic/remove {id}`, AdminKey/роль admin) — у колоді біля
  кожної картинки «🗑», коли `deck.admin`.
- Свої картинки йдуть у загальний пул (`all`, підпис «картинка від <нік>») і в «мої». Автор може сховати свою.
- **Автору +1 черепок** щоразу, як її склав хтось інший у партії від двох людей (не вечірка, не з ботом) —
  `Economy.GrantCapped`, стеля 30 на добу (`sklei-author`). Робить фон (`SkleiDeck`): гра лише кидає подію.

Ендпоінти (`/api/games/sklei/…`):

| запит | відповідь |
|---|---|
| `GET deck` | `{builtin: [{id, title, url}], photos, arts, own: [{id, url, by, at, hidden, solved}], price, account, balance, admin}` |
| `GET mine` | `{account, items: [{id, url, by, at, hidden, solved}]}` — мої, і сховані |
| `POST pic` (тіло — файл) | `{ok, message, pic?}`; 400 з `message` — відмова (тост) |
| `POST pic/hide {id, hidden}` | `{ok, message, pic}` |
| `POST pic/remove {id}` | лише адмін → `{ok, message}` |
| `GET pic/<file>` | файл картинки (кеш на рік) |
| `GET art/<id>` | `{id, word, by, z}` — малюнок Піктіонарі |

## 7. Режим вечірки

`Sklei : IPartyMinigame`. `party=1` → **одна картинка «звично»** (16, з поворотами; на телефоні теж 16), «Готуйсь» 2 с,
складання **60 с**, стеля **75 с**; картинки — вбудовані й малюнки друзів (без фото й своїх). Боти — на місцях `bots`,
рівень `botlvl`. Кінець — склали всі або 60 с → `Finish` з **scores кожного місця**: склав — `1000 − секунди`
(ціла частина), не склав — скільки черепків приросло (0..16). Без Award/Score, без Глека в балачці, «🤖 + бот» — ні.
Вихід посеред — місце просто не складає. 2–8 гравців.
`Howto`: «Перетягни кожен черепок на його місце й поверни рівно — приросте сам. Тап по черепку — поворот (на ПК ще
колесо чи правий клік); склав першим — ти вгорі».

## 8. Ачівки й Глек

- `sklei-restorer` «Реставратор» — склав усі картинки партії на «важко»/«майстер» без жодного хибного повороту
  (гра, `Ctx.Award`, партія від двох людей).
- `sklei-friends` «Чужими руками» — склав 10 малюнків і своїх картинок друзів (лічильник у `sklei_stats`, фон).
- `sklei-author` «Автор» — твою картинку склали 25 разів (фон, `Achievements.Unlock`).
- Дядько Глек: на старті («Розбили — склеїмо. Не вперше.»), коли людина склала першою в партії, і в кінці — переможцю.
  У вечірці мовчить.

## 9. Клієнт (етап Б) — що зробити

Модуль `web/games/sklei.js` + `.css`: рамка N×N з контуром (`hint`), стіл із черепками (`tray`), drag мишею/пальцем,
поворот (тап / колесо / правий клік, лише +90°), магніт і `put`, прогрес інших (`players[].placed/of`), підсумок
картинки (`pause`, `history`), колода (`GET deck`, «🗑» адміну), «Своя картинка» (обрізка квадрата як у Лавці,
`POST pic`, ціна й баланс), «Мої картинки» (сховати). `dev {phone}` на mount. Пад: стік — курсор, A — взяти/покласти,
X — поворот. `added: '2026-10-06'`, іконка `gico`. Вечірка: `HGames.embed`, нічого поза `root`.
