# Глек-слово (`wordle`) — пункт 41

**Info:** `Id="wordle"`, `Title="Глек-слово"`, `Accusative="Глек-слово"`, `Group=Solo`, 1/1,
`Start=Immediate`, `Private=true`, `Persistent=true`, `Score=LowerIsBetter` (спроб), зареєстровано в
`Daily` (specs/daily.md), `Hint="П'ять літер, шість спроб. Одне слово на день — на всіх. Зелена — на місці, жовта — є, але не тут"`.
Потребує WP4: `Words.Daily5(seed)` (з `uk-5.txt`), `Words.IsValid5(word)` (з `uk-guess.txt` ∪ `uk-5.txt`).

## Правила

- Слово дня: `Words.Daily5(Daily.Seed("wordle"))` — детермінований вибір індексу зі списку відповідей (без
  повторів у межах 365 днів: індекс = перестановка списку за сідом року? Простіше: `seed % count`; тест
  лише на детермінізм). Ключ кімнати: `daily:wordle:<day>:<nick_key>`.
- 6 спроб. `guess {word}`: 5 літер кирилицею (ґ, є, і, ї, й дозволені; апостроф — ні); не в словнику —
  Fail «Такого слова не знаю»; уже відгадано/спроби вичерпані — Fail.
- Оцінка: класична (з правильним підрахунком дублів літер: спершу зелені, потім жовті в межах кількості).
- Вгадав → `solved=true`, `attempts=n`, `Ctx.Score(0, n)` і `Award(0, DailyReward, "daily:wordle")`
  (ref за днем — раз на день). Не вгадав за 6 → `failed=true`, слово показується.
- Серія (streak) — рахує WP1 з `daily_results` (Daily API); гра лише пише результат.
- Ділитись результатом: вид містить `share` — рядок емодзі-сітки («Глек-слово #123 4/6 🟩🟨⬛…») для
  кнопки «Скопіювати».
- Persistent: `Save()` = `{ day, guesses: [...], solved, failed }`; `Load` відновлює; інший день → чистий стан.

## Дії

`guess {word}`.

## Вид

```ts
{ day: string, no: number,               // порядковий номер дня від 2026-09-10
  rows: { word: string, marks: string }[],  // marks: 'GYB' × 5 (green/yellow/black)
  attempts: number, max: 6, solved: boolean, failed: boolean,
  answer: string|null,                   // лише коли solved або failed
  keys: Record<string, 'G'|'Y'|'B'>,     // зведений стан літер для клавіатури
  share: string|null }
```
До кінця у виді **нема** відповіді (тест).

## Клієнт

- 6×5 сітка плиток, анімація перевороту рядка (CSS), екранна клавіатура `keyboardUa` з кольорами `keys`,
  фізична клавіатура через `onKey` (Enter — спроба, Backspace). Кнопка «Скопіювати результат» після кінця.
  Показ «Наступне слово через 5 год 12 хв» (до опівночі Києва — з `Daily` API або обчислення на клієнті
  за `day`).
- Панель «Щоденний глек» (WP2) відкриває цю кімнату через `OpenSolo('wordle')`.

## Тести (≥ 20)

- Оцінка з дублями: відповідь «калина», спроба «лілія» → правильні кольори; повний набір класичних кейсів.
- Невідоме слово — Fail без витрати спроби; 7-ма спроба — Fail; після розв'язання — Fail.
- Детермінізм слова дня; різні дні — різні слова (на 30 днях ≥ 25 різних).
- `Load(Save())`; інший день → чисто; `share` формат; `keys` зведення (зелена перекриває жовту).
- Score і Award викликані один раз.
