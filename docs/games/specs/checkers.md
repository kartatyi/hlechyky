# Шашки (`checkers`) — пункт 13

**Info:** `Id="checkers"`, `Title="Шашки"`, `Accusative="шашки"`, `Group=Board`, 2/2, `Rated=true`,
`Hint="Російські шашки: бити обов'язково, дамка ходить на всю діагональ"`. `SeatName`: «білі»/«чорні».
Місце 0 — білі в першій партії, «Ще раз» обертає.

## Правила (російські шашки — ті, у які тут грають)

- Дошка 8×8, 12 шашок у кожного на темних полях (a1 темне). Білі починають.
- Проста шашка ходить на одне поле вперед по діагоналі; **б'є** вперед і назад через сусідню чужу на
  вільне поле за нею.
- Дамка ходить на будь-яку кількість вільних полів по діагоналі; б'є чужу на будь-якій відстані, якщо за
  нею є вільне поле, і може стати на будь-яке вільне поле за побитою (але якщо звідти є продовження взяття —
  мусить продовжувати).
- **Взяття обов'язкове.** Серед кількох взять — будь-яке на вибір (не обов'язково більше). Почав бити —
  мусиш дібрати ланцюг до кінця. Побиті шашки знімаються після завершення ланцюга (турецький удар:
  через одну шашку двічі не б'ють, і вона лишається на дошці до кінця ланцюга як перешкода).
- Шашка, що дійшла до останньої лінії ходом — стає дамкою; якщо дійшла посеред ланцюга взяття — стає
  дамкою і **продовжує бити як дамка** в тому ж ланцюзі.
- Перемога: у суперника нема шашок або нема ходу. Нічия: 15 ходів дамками без взяття і руху простих
  (спрощене правило), або триразове повторення позиції, або взаємна згода (`draw`).

## Дії

| action | payload | Примітки |
|---|---|---|
| `move` | `{ path: ["c3","d4"] }` або `{ path: ["c3","e5","g3"] }` для ланцюга взять | Весь ланцюг за один Act. Неповний ланцюг (є продовження) — Fail «Треба дібрати до кінця». Хід без взяття, коли взяття є — Fail «Бити обов'язково». |
| `resign`, `draw`, `decline` | — | як у шахах |

## Вид

```ts
{
  board: string,          // 64 символи a8..h1: 'w' біла, 'W' дамка, 'b'/'B' чорні, '.' порожньо, ' ' світле поле
  turn: 0|1, toMove: 'w'|'b',
  legal: string[][],      // усі легальні ланцюги того, хто ходить, кожен — масив полів; для «тільки взяття» тут лише взяття
  mustCapture: boolean,
  lastPath: string[] | null,
  count: { w: number, b: number },
  drawOffer: 0|1|null,
  result: null | { winner: 0|1|null, reason: 'nopieces'|'nomoves'|'resign'|'agreed'|'repetition'|'kings15'|'left' }
}
```

## Клієнт

- Дошка як у шахів (спільний CSS можна повторити у своєму `checkers.css`, не імпортуючи chess.css).
- Клік по шашці → підсвітити перші кроки всіх `legal` з неї; клік далі — будуємо ланцюг; коли ланцюг
  збігся з повним легальним — `act('move')`. Кнопка «Скинути вибір».
- Показувати «Бити обов'язково», коли `mustCapture`.

## Тести (≥ 30)

- Початкова розстановка: 12/12, білі ходять, 7 легальних ходів.
- Обов'язкове взяття: хід без взяття — Fail; взяття виконано, шашка знята.
- Ланцюг із 3 взять; неповний ланцюг — Fail; турецький удар (побита стоїть до кінця ланцюга, через неї не б'ють).
- Взяття назад простою; дамка б'є на відстані; дамка після взяття мусить продовжити, якщо є куди.
- Перетворення в дамку ходом; перетворення посеред ланцюга і продовження дамкою.
- Перемога без шашок; перемога, коли нема ходу (замкнені); 15 ходів дамками → нічия; повторення.
- Вид: `legal` порожній після Finish; `board` 64 символи; детермінізм.

## Як реалізовано

### Дошка й правила

- Поля нумеруються так само, як їх бачить браузер у `board`: 0 — a8, 63 — h1
  (`index = (8 - ранг) * 8 + файл`). Темне поле — те, де сума ряду й колонки непарна (a1 темне).
- Стан дошки — `char[64]`: `w`/`W`/`b`/`B`, `.` — порожнє темне поле, пробіл — світле. `View` віддає
  його рядком без перетворень, тому вид і внутрішній стан неможливо розсинхронити.
- `CheckersRules` — статичний клас без стану: `Captures(board, from)` віддає **повні** ланцюги
  (з останнього поля бити вже нема кого), `Quiet(board, from)` — ходи без взяття, `MustCapture(board, side)`
  спиняється на першому знайденому ланцюзі, `Legal(board, side)` збирає легальні ходи сторони.
- Турецький удар зроблено списком уже побитих: вони **не** знімаються з дошки під час пошуку, тому
  крізь них не б'ють удруге і за ними не приземляються. `Apply` знімає їх аж після завершення ланцюга.
- Проста, що приземлилась на останню лінію посеред ланцюга, далі шукає взяття вже як дамка (`Crown`).
- Хід гравця перевіряється звіркою з переліком ланцюгів саме цієї шашки: точний збіг — хід,
  строгий префікс — «Треба дібрати до кінця», простий хід при наявному взятті — «Бити обов'язково».

### Рішення, які spec лишав на розсуд

- **`legal` має стелю** `CheckersRules.MaxChains = 500`. На дошці з кількома дамками кількість
  комбінацій приземлень зростає швидко, а вид летить у браузер на кожен хід. У живій партії ланцюгів
  одиниці, тож стеля не спрацьовує; законність ходу вона не звужує — хід звіряють із ланцюгами
  **однієї** шашки, а їх завжди мало.
- **«15 ходів дамками» рахуються півходами** — по одному на кожен `Act`, як каркас рахує `Room.Moves`.
  Лічильник обнуляє будь-яке взяття і будь-який хід простої (обидва незворотні); разом із ним
  обнуляється й історія позицій для повторення.
- **Триразове повторення** — за ключем «дошка + хто ходить», позиції записуються після кожного ходу.
- **Кольори прив'язані до місць, а не до людей**: місце 0 — завжди білі. «Ще раз» обертає місця сам
  (це робить каркас), тож той, хто грав чорними, наступну партію починає білими; обертати кольори ще
  й у грі означало б обернути двічі.
- `resign` / `draw` / `decline` — як у шахах: пропозицію знімає будь-який хід суперника, друга
  пропозиція від того самого місця — відмова «Пропозиція вже висить».
- `OnLeave` дає технічну поразку і ставить `result.reason = "left"`.
- `Save()`/`Load()` реалізовані, хоча гра не `Persistent`: стан цілком серіалізовний, і тести
  ставлять позиції саме через `Load` — тим самим шляхом, яким стан підіймав би сервер.

### Клієнт

- Дошка — сітка каркаса `HGames.ui.grid` із класом `ck`: спільна механіка оновлення, свої кольори.
- Клік по шашці підсвічує перші кроки її ланцюгів, кожен наступний клік добудовує шлях; коли шлях
  збігся з повним легальним ланцюгом — летить `act('move', { path })`. Повний ланцюг ніколи не є
  початком іншого повного, тож збіг довжини однозначно означає кінець ходу.
- Скинути вибір: кнопка «Скинути вибір» або Escape. Клік по іншій своїй шашці починає вибір із неї.
- Чорним дошка показується з їхнього боку (поворот на 180° — це `63 - i`).
- «Бити обов'язково» — у смужці над дошкою, поруч із рахунком шашок. Під дошкою — «Нічия?» і
  «Здатись», а коли нічию пропонує суперник — «Згода» / «Ні».
- Мобільний: на 375 px дошка 305 px, клітинка 38 px, горизонтального скролу нема; окремої хрестовини
  тут не треба — керування це тап по полю і кнопки під дошкою.

### Обмеження

- Нічия «за домовленістю» і `decline` доступні будь-коли під час партії, не лише у свою чергу.
- `legal` перераховується на кожен `View`. Для 8×8 це дешево, але якщо колись з'явиться гра з
  тією ж дошкою і 25 Гц, перелік треба буде кешувати.

### Як перевірити руками

1. `dotnet test tests/Hlechyky.Tests/Hlechyky.Tests.csproj -nodeReuse:false` — зелено.
2. Сервер на своєму порту, дві вкладки з різними origin (`localhost` і `127.0.0.1`) → різні ніки.
3. Стіл «Шашки» → сісти другим → перший хід: клік по шашці підсвічує два поля, клік по полю ходить.
4. Підставити шашку під бій: у суперника має з'явитись «Бити обов'язково», а всі інші шашки —
   перестати підсвічуватись.
5. Ланцюг із двох взять: перший клік по проміжному полю **не** відсилає хід (статус лишається
   «Твій хід»), відсилає лише останній.
6. «Нічия?» → у суперника «Пропонують нічию / Згода / Ні»; «Ні» знімає пропозицію.
7. «Здатись» → Журнал «X здається — Y білі 1:0 X чорні», тост гаманця, «Ще раз» обертає місця
   (дошка в того, хто став чорним, перевертається).
8. «Встати» посеред партії → технічна поразка, `result.reason = "left"`.
9. F5 посеред партії → місце вціліло (grace), картка відновилась із тією ж позицією.
