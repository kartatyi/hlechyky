# Шашки (`checkers`) — пункт 13

**Info:** `Id="checkers"`, `Title="Шашки"`, `Accusative="шашки"`, `Group=Board`, 2/2, `Rated=true`,
`Hint="Російські шашки: бити обов'язково, дамка ходить на всю діагональ"`. `SeatName`: «білі»/«чорні».
Місце 0 — білі в першій партії, «Ще раз» обертає.

## Правила (російські шашки — ті, у які тут грають)

- Дошка 8×8, 12 шашок у кожного на темних полях (a1 темне). Білі починають.
- Проста шашка ходить на одне поле вперед по діагоналі; **б'є** вперед і назад через сусідню чужу на
  вільне поле за нею.
- Дамка ходить на будь-яку кількість вільних полів по діагоналі; б'є чужу на будь-якій відстані, якщо за
  нею є вільне поле, і може стати на будь-яке вільне поле за побитою (але якщо звідти є продовження взяття —
  мусить продовжувати).
- **Взяття обов'язкове.** Серед кількох взять — будь-яке на вибір (не обов'язково більше). Почав бити —
  мусиш дібрати ланцюг до кінця. Побиті шашки знімаються після завершення ланцюга (турецький удар:
  через одну шашку двічі не б'ють, і вона лишається на дошці до кінця ланцюга як перешкода).
- Шашка, що дійшла до останньої лінії ходом — стає дамкою; якщо дійшла посеред ланцюга взяття — стає
  дамкою і **продовжує бити як дамка** в тому ж ланцюзі.
- Перемога: у суперника нема шашок або нема ходу. Нічия: 15 ходів дамками без взяття і руху простих
  (спрощене правило), або триразове повторення позиції, або взаємна згода (`draw`).

## Дії

| action | payload | Примітки |
|---|---|---|
| `move` | `{ path: ["c3","d4"] }` або `{ path: ["c3","e5","g3"] }` для ланцюга взять | Весь ланцюг за один Act. Неповний ланцюг (є продовження) — Fail «Треба дібрати до кінця». Хід без взяття, коли взяття є — Fail «Бити обов'язково». |
| `resign`, `draw`, `decline` | — | як у шахах |

## Вид

```ts
{
  board: string,          // 64 символи a8..h1: 'w' біла, 'W' дамка, 'b'/'B' чорні, '.' порожньо, ' ' світле поле
  turn: 0|1, toMove: 'w'|'b',
  legal: string[][],      // усі легальні ланцюги того, хто ходить, кожен — масив полів; для «тільки взяття» тут лише взяття
  mustCapture: boolean,
  lastPath: string[] | null,
  count: { w: number, b: number },
  drawOffer: 0|1|null,
  result: null | { winner: 0|1|null, reason: 'nopieces'|'nomoves'|'resign'|'agreed'|'repetition'|'kings15'|'left' }
}
```

## Клієнт

- Дошка як у шахів (спільний CSS можна повторити у своєму `checkers.css`, не імпортуючи chess.css).
- Клік по шашці → підсвітити перші кроки всіх `legal` з неї; клік далі — будуємо ланцюг; коли ланцюг
  збігся з повним легальним — `act('move')`. Кнопка «Скинути вибір».
- Показувати «Бити обов'язково», коли `mustCapture`.

## Тести (≥ 30)

- Початкова розстановка: 12/12, білі ходять, 7 легальних ходів.
- Обов'язкове взяття: хід без взяття — Fail; взяття виконано, шашка знята.
- Ланцюг із 3 взять; неповний ланцюг — Fail; турецький удар (побита стоїть до кінця ланцюга, через неї не б'ють).
- Взяття назад простою; дамка б'є на відстані; дамка після взяття мусить продовжити, якщо є куди.
- Перетворення в дамку ходом; перетворення посеред ланцюга і продовження дамкою.
- Перемога без шашок; перемога, коли нема ходу (замкнені); 15 ходів дамками → нічия; повторення.
- Вид: `legal` порожній після Finish; `board` 64 символи; детермінізм.
