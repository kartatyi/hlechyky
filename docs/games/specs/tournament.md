# Турнір на вечір

Кілька ігор поспіль для однієї компанії: за кожну гру — турнірні очки за місце, наприкінці чемпіон отримує 👑 біля
ніка (у балачках і в списку «хто на сайті») до наступного турніру. Турнір один на сайт.

Файли: `src/Hlechyky/Games/Tournament.cs` (сервіс, підключено в `GamesSetup`), методи хаба в `RadioHub.cs`
(розділ «турнір»), панель `web/games/tournament.js` + `.css` (вкладка «👑 Турнір» у «Іграх»), корона й автоперехід
за стіл — у `web/app.js`. Тести: `tests/Hlechyky.Tests/Platform/TournamentTests.cs`.

## Як іде

1. **Збір.** Хтось обирає 2–6 ігор (для кількох гравців, не соло) у потрібному порядку й тисне «Зібрати турнір» —
   у Журналі з'являється заклик. Інші тиснуть «Я в турнірі». Вийти можна будь-коли.
2. **Гра.** Той, хто збирав, тисне «Почати» / «Далі». Сервер сам: звільняє учасникам місця за дограними столами,
   ставить стіл наступної гри (господар стола — перший учасник на сайті), садить усіх учасників, які зараз на сайті,
   і стартує партію. Хто з учасників у «Іграх» — одразу опиняється за столом; хто деінде — отримує тост.
   Не вийде, якщо учасників на сайті замало/забагато для гри або хтось сидить за іншим живим столом — причина
   приходить тостом.
3. **Очки.** Партія скінчилась — місця: є рахунок — за рахунком (рівний рахунок — рівне місце); нема — переможці
   перші, решта другі, нічия — усі перші. Очки = скільки гравців у грі − місце + 1 (утрьох 3, 2, 1). Результат —
   рядком у Журналі.
4. **Кінець.** Після останньої гри (або «Завершити зараз») чемпіон — хто з найбільшими очками (кілька — всі).
   Корона зберігається в `game_state` під ключем `tournament:crown` і переживає рестарт.

Гра зависла (усі розбіглись) — «Пропустити гру». Стіл поточної гри зник — гра сама рахується пропущеною.
Господаря турніру нема на сайті — керувати може будь-хто з учасників.

## Дріт

Хаб: `TournamentCreate(string[] games)`, `TournamentJoin()`, `TournamentLeave()`, `TournamentNext()`,
`TournamentSkip()`, `TournamentCancel()` — кожен повертає текст відмови або `null`. Після кожної зміни всі
отримують подію `tournament`; при підключенні — теж.

```ts
{ active, id, host, stage: 'gathering'|'playing'|'between'|'done', index,
  games: { id, title }[], players: nick[], online: nick[],
  standings: { nick, points }[], results: { game, title, skipped, places: { nick, place, points, score }[] }[],
  room: null | { id, status }, champions: nick[], crown: nick[] }
// турніру нема: { active: false, crown }
```

## Оновлення 24.09.2026

- **Переможець вище за переможеного, навіть із меншим рахунком.** `Places` для ігор із рахунком ставила
  місця лише за рахунком і не дивилась на `winners`. У сапері той, хто наступив на міну, часто має більше
  відкритих клітинок — і в турнірі діставав перше місце за програну партію. Тепер переможці завжди вище, а
  рахунок розводить гравців усередині кожної купки (тести `A_winner_with_the_smaller_score_…`, `Among_losers_…`).
- **«Пропустити гру» більше не роздає очок.** `Skip` спершу виганяв гравців з-за живого столу, а вже потім
  рахував гру пропущеною — і техпоразка першого, хто «встав», потрапляла в турнір як справжній результат:
  решта отримувала очки. Тепер гра спершу стає пропущеною, потім учасники встають (тест `Skipping_a_live_game_gives_nobody_points`).
- **Пропустити можна й наступну гру — між іграми і ще на зборі.** Раніше гра, у яку нинішній склад не влазить
  (хрестики на двох, а вас троє), ставала стіною: `Next` відмовляв, а `Skip` працював лише посеред партії, тож
  лишалось хіба скасувати турнір. У панелі — кнопка «Пропустити «…»» поруч із «Почати»/«Далі» (тест
  `A_game_that_does_not_fit_the_company_can_be_skipped_between_games`).
- У підсумках пропущена гра підписана «пропущено», а не «не дограли».
- Турнір охоче бере нову гру «Глек-слово наввипередки» (2–6) — перевірено в браузері втрьох: стіл
  поставився сам, усіх посадило, очки порахувались.

Відоме й не виправлене: у Журналі рядки турніру («🏆 Турнір, …», «👑 Чемпіон…») виходять раніше за рядок
самої партії — турнір пише в Журнал одразу, а кімната — своєю розсилкою після ходу. Лікувати це треба в
тому, як `Tournament` поштує рядки (через `Outbox` кімнати), — не став чіпати без потреби.
