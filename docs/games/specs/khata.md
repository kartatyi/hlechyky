# Здам хату (`khata`)

**Info:** `Id="khata"`, `Title="Здам хату"`, `Accusative="«Здам хату»"`, `Group=Party`, 1/12, `Start=ByHost`,
`Hidden=true` (ціни приховані до розкриття), `TickMs=1000`, `Rated=false`.

Задум (17.11.2026, рішення користувача в раунді `orenda-gra`): гравець бачить **фото квартири й місто — більше нічого**,
і вгадує ціну оренди за місяць. Що ближче — то більше балів. Опису квартири нема свідомо («опису не треба, тільки фото
і місто»). Банк квартир наповнюють самі гравці, розробник схвалює. Родич «Скільки?»: ті самі фази й той самий тик.

## Правила

- Партія — 5 квартир (опція «Квартир»: 3/5/7/10). Якщо в банку для обраних міст менше — стільки, скільки є.
- Раунд: `between` 3 с («Готуйсь») → `ask` 30 с (опція «Час на відповідь»: 20/30/45/60) → `reveal` 8 с → наступний.
  У `between` ні фото, ні міста у виді нема. Усі відповіли — розкриття найближчим тиком.
- Відповідь — `answer {value}`: число або рядок («15000», «15 000», «15к», «1,5 тис», «$1200»). Можна змінювати, поки є
  час. Нуль і від'ємне — відмова. Хто промовчав — 0.
- **Бали** (`Khata.Points`), до 1000 за квартиру, кожне число оцінюється саме, без огляду на суперників:
  `off = |ln(моє / правда)|`; у межах 2 % (`off ≤ ln 1,02`) — 1000; далі `1000 · e^(−3 · (off − ln 1,02))`.
  Орієнтири: 10 % — 797, −20 % і +25 % — 543 (це те саме «у 1,25 раза»), удвічі — 133, утричі — 39.
  Удвічі дешевше й удвічі дорожче — однаково далеко. Бонусів найближчому чи швидшому нема.
- **Валюта** — за регіоном квартири: Україна — гривні (`₴`), Європа й світ — долари (`$`). Знак стоїть біля поля.
- **Опція «Міста»** (кілька): усі / Україна / Європа / Світ. Регіон вказує той, хто додає квартиру.
- **Автор за столом.** Квартири тих, хто сидить за столом, ідуть у самий кінець черги (беруться, лише коли інших
  бракує). Якщо таки випала — у компанії автор її пропускає (ціну знає), розкриття його не чекає. Сам на сам автор
  грає й свої (інакше нема в що), але без черепків за них.
- **Пам'ять** — спільна `game_seen` (`GameSeen`, ключ гри `khata`, ключ квартири `f<id>`): спершу квартири, яких ніхто
  за столом не бачив, далі бачені найдавніше. «Бачив» — з моменту, коли квартира з'явилась на екрані.
- **Кінець:** переможці — усі з найбільшим рахунком (якщо він > 0); нуль у всіх — нічия. Хтось встав — решта грає далі;
  за столом нікого — партію закрито.
- **Черепки за бали:** `бали / 500` (`PointsPerShard`, далі × `Economy:Boost`) — але лише за квартири, які місце бачить
  **уперше** й не саме додало (`result.fresh`). Банк малий і ціни запам'ятовуються — напам'ять нафармити не вийде.
  Звичайна виплата каркаса за перемогу/участь у компанії — окремо, як у всіх.
- Дядько Глек коментує розкриття на картці (`reveal.say`, 21 статична фраза, нік у називному; коли ціну назвав лише
  один — свій набір без «найближче» й «решта»).

## Банк квартир (`KhataStore`)

- Таблиця `khata_flats(id, region, city, price, photos(JSON-масив імен), author, author_key, at, status, removed)`;
  фото — `data/khata/<20 hex sha256>.<jpg|png|webp>`. Тека `data/` не в гіті — банк живе лише на сервері.
- Додає **акаунт**: регіон, місто (2–40 знаків), ціна за місяць, 1–5 фото. Фото стискає браузер (JPEG, довша сторона
  ≤ 1280, ≤ 380 КБ; через canvas — EXIF із геоміткою не переживає); сервер звіряє магічні байти, вагу (≤ 400 КБ) і
  розміри (240–1920 px). Те саме фото вдруге (в будь-якій квартирі) — відмова.
- Від розробника квартира одразу `ok`; від решти — `pending`, доки розробник не схвалить. Не більше 10 `pending` на автора.
- За схвалену квартиру автору — 30 черепків × Boost, раз на квартиру (ref `khata-flat:<id>`).
- Розробник може виправити місто/регіон/ціну (`Edit`) і зняти будь-яку; автор — зняти свою. Зняття позначає рядок
  і прибирає файли.
- Гра читає банк під замком кімнати — лише знімок у пам'яті (`Live`); база й диск — тільки з HTTP.

## HTTP (`KhataSetup`)

| Метод | Адреса | Що |
|---|---|---|
| GET | `/api/games/khata/bank` | `{ total, byRegion, account, admin, reward, limits, mine[], pending, all[] }`; `all` — лише розробнику |
| POST | `/api/games/khata/flat` | `{ region, city, price, photos: [base64…] }` → `{ ok, message, flat? }` |
| POST | `/api/games/khata/flat/approve` | `{ id }` — розробник |
| POST | `/api/games/khata/flat/edit` | `{ id, region, city, price }` — розробник |
| POST | `/api/games/khata/flat/remove` | `{ id }` — автор або розробник |
| GET | `/api/games/khata/pic/<файл>` | фото; тип за магічними байтами, кеш на рік |

Чужих цін звичайний гравець із `/bank` не отримує (це відповіді): `mine` — лише свої, `all` — лише розробнику.

## Вид (Hidden)

```ts
{ round, of, phase: 'between'|'ask'|'reveal'|'done', city: string, unit: '₴'|'$'|null, photos: string[],
  endsAt: string (ISO), seconds, answered: boolean[], my: number|null, own: boolean,
  reveal: null | { price, by, say, rows: [{ seat, value, ratio, points }] },
  scores: number[], names: (string|null)[],   // names — хто на якому місці починав партію (устав — нік лишається)
  result: null | { winners: number[], scores: number[], fresh: number[] },
  recap: null | [{ city, unit, price, photo, best: number|null, value, points }],
  bank: { fit, total } }
```
Кадр: `{ round, of, phase, endsAt, answered, scores }` — лише разом із новиною (чиєсь число, зміна фази).

## Клієнт (`web/games/khata.js`, `.css`)

- Фото — карусель (‹ ›, крапки, змах пальцем), тап — на весь екран (оверлей у `body`, Esc і стрілки). Під фото — місто
  великим, поле ціни зі знаком валюти, «= 15 000 ₴» під полем, поки набираєш.
- Розкриття: справжня ціна, хто додав квартиру, рядки від найближчого з промахом («+25 %», «у 3 раза дорожче»),
  смужка-частка від 1000 за кожним рядком, слово Глека. Кінець: переможець, «Як це було» з мініатюрами.
- У лобі й після партії — «🏠 У банку N квартир»: «Додати квартиру» (форма з регіоном, містом, ціною й фото), «Мої
  квартири»; розробнику — «Чекають на схвалення» (✓ Схвалити, ✎, 🗑) і «Усі квартири в грі».
