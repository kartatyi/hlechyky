## 2. Як викликати (для пакета C і ядра)

```js
api.sceneGuest(key);        // на кожній своїй картці — так, як у контракті: api.sceneGuest?.(key)
api.sceneGuest(st, key);    // на одній картці
// key: 'tsargrad' | 'canton' | 'diaspora' | 'london' | 'paris' | 'masters'
// → true: гість їде або став у чергу; false: невідомий ключ або чужа картка

el.innerHTML = api.coinSvg('hryvnia');   // «📜 Гетьманський універсал»
el.innerHTML = api.coinSvg('gold');      // «💰 Червоні золоті»
```

Звуків не додавав: пакет C кличе `api.sfx('guest')` (синонім `catch`, уже є).

## 3. Продуктивність

- Усе нове — частина рядка хати: `envOf` кладе рівні дванадцяти щаблів сходинками (1/25/50/100) у той самий `tiers`,
  тож хата перемальовується лише тоді, коли щабель переступив сходинку (підпис `houseSig`, як і було).
- Жодної роботи щокадру: `frame()`/`slow()` не чіпав, `getBoundingClientRect`/`getClientRects` не додавав.
- Рух — CSS `transform`/`opacity`: на всіх 100-х рівнях це 14 нових анімацій (потяг і два клуби диму, шлюп,
  пароплав і два клуби, далеке вітрило, промінь маяка, два спалахи феєрверку, два клуби над школою й прапор) — у хаті
  Владіка стало 77 анімацій. Дим без `filter: blur` (на рухомій групі він дорогий). Сцена поза екраном — усе на
  паузі (`clks-off`, як і було); `prefers-reduced-motion` — нуль анімацій у хаті, транспорт і гість стоять на місці,
  годинник прибирає гостя через хвилину.
- Рядок хати Владіка на 100-х рівнях: ~103 КБ замість ~79 КБ — будується рідко (див. вище).

## 4. Вставки в наявні функції `clicker-scene.js` (дослівно)

Чужих файлів не чіпав. Але `clicker-scene.js` паралельно править пакет B, тож ось усі рядки, додані в **наявні**
функції (решта — нові функції одним блоком перед `const DEFS` і нові записи в кінці `EMBLEM`):

1. `worldSvg` — після блоку Цар-глека, перед «// Річка з чайкою.»:
   ```js
       s += worldFar(e);                     // v10: вежа, вокзал, маяк, потяг за річкою
   ```
2. `worldSvg` — після блоку чайки, перед «// Ближня земля, дорога.»:
   ```js
       s += worldRiver(e);                   // v10: вітрило, причал і шхуна, шлюп і пароплав
   ```
3. `worldSvg` — одразу після рядка з дорогою (`...style="fill:var(--clks-road)"/>';`):
   ```js
       s += worldRoad(e);                    // v10: миргородська калюжа й школа
   ```
4. `worldSvg` — після `s += fenceSvg(e);`:
   ```js
       s += worldFront(e);                   // v10: заморські гості й прапорці фестивалю
   ```
5. `roofSvg` — перед `return s;`:
   ```js
       s += worldRoof(e);                    // v10: дошка з курсом глека
   ```
6. `interiorSvg`, горно — після `+ stoveTiles(e)`:
   ```js
           + worldKiln(e)                    // v10: батуринські зелені кахлі
   ```
7. `interiorSvg` — було `s += decor2Svg(e) + wonderShelf(e) + showShelf(e);`, стало:
   ```js
       s += decor2Svg(e) + wonderShelf(e) + showShelf(e) + worldShelf(e);
   ```
8. `envOf` — після `for (const k of TIERS) tiers[k] = step(lvl(k));`:
   ```js
       for (const k of WORLD) tiers[k] = step(lvl(k));
   ```
9. `paintHouse` — після `st.house.innerHTML = houseSvg(e);`:
   ```js
       guestPlace(st);                       // гість посеред візиту переїжджає в новий малюнок
   ```
10. `mount` — у `st.scn` дописано поле `guest: null, guestQueue: [], guestNext: 0,`; після `api.houseSvg = …`
    — `api.sceneGuest` і `api.coinSvg` (див. §2).
11. `unmount` — перед `st.scn = null;`:
    ```js
          clearTimeout(st.scn.guestNext);
          if (st.scn.guest) clearTimeout(st.scn.guest.timer);
    ```

Місця, де читаються тексти хати (`house.wonders/looks/decor/tools`), і виклики `api.visible` не змінювались.

## 5. Що перевірено в браузері

Свій headless Chrome (`cdp.py --port 9424`), сервер на 8214, копії прод-збережень.

- **Старі гравці не бачать змін:** рядок хати зі старим і новим `clicker-scene.js` байт у байт однаковий для
  `тест-владік` (72 421 байт), `тест-назар` (62 144) і новачка `тест-mariana` (11 634) — додано лише п'ять порожніх
  гнізд для гостей (214 байт). (Після окремого коміту про прапорці — ще й без жовтого клинця на вимпелі Школи
  гончарів, див. §6.)
- **`тест-владік` зі справжнім збереженням:** рівні дванадцяти щаблів прописано скриптом у dev-базу при зупиненому
  сервері — усі на 1, потім усі на 100; знімки 1920×1080 і 390×844 (сторінка й сцена ×2), удень і вночі
  (`HClicker.sceneTime`), з потягом і кораблями, зупиненими посеред кадру (Web Animations API). 25 і 50 — через
  підміну рівнів у виді.
- **Гості:** `api.sceneGuest` для кожного з шести ключів, знімки на 5 с (прибуття), 30 с (гість біля хвіртки) і 74 с
  (карета розвернулась і їде назад). Логіка: невідомий ключ → `false`; `(st, key)` і `(key)`; черга без повторів;
  перемальовка хати посеред візиту — вузли на місці, анімація триває (2,47 с → 2,78 с, а не з нуля); після
  від'їзду черга привозить наступного через 1,5 с.
- **Reduced motion** (емуляція медіа): у хаті 0 запущених анімацій, потяг стоїть посеред поля, карета — на зупинці,
  гість видимий, годинник на 60 с.
- **Хата друга** (`api.houseSvg`) малює новий світ, id з префіксом `clksf-`, жодного `id="clks-` не лишилось.
- **Монети й значки** — окремим стендом на 32/64/128 px.
- Телефон 390 px — без горизонтальної прокрутки (scrollWidth 390). Консоль чиста (крім старих помилок SignalR після
  перезапуску сервера).
- Прапорці: рівні Опішні 1/25/50/100 і гості з прапорцями (Царград, діаспора, Лондон, куля гончарів) — на знімках
  лише одноколірні трикутники.

## 6. Обмеження

- Гості прибувають лише тоді, коли пакет C кличе `api.sceneGuest` — у цій гілці його перевірено стендом.
- Корабель гостя зупиняється праворуч на річці; школа Миргорода (щабель 21) стоїть на ближньому березі перед ним і
  з часом заступає корпус — вітрила й вимпел видно. Так задумано: школа ближче.
- Коли дивовиж 13–16 і всі чотири дрібні дива куплені, полиця див піднімається на y 198 — трохи заходить на рушник
  над колом. Зараз найбільше дивовиж у Smaug (12) — у нього все стає в ряд.
- **Прапорці на сцені — лише одноколірні трикутні вимпели** (і глечики на гірлянді): жодних смугастих чи схожих
  на державні. «Гості з усіх країн» (Опішня 50) — більше барв і глечики різної поливи. Окремим комітом прибрано й
  двоколірні вимпели, що лишались: шхуна й школа Миргорода (були синьо-жовті), кормовий прапор корабля
  царградських купців, прапорець пароплава діаспори (був червоно-білий прямокутник) і потяга лондонців — тепер
  трикутні однієї барви; а ще старий (з v7) вимпел «Школи гончарів» на пагорбі — був синій із жовтим клинцем,
  став просто синій. Це єдина зміна, яку побачать і нинішні гравці зі Школою гончарів від 25-го рівня.
