# Цеглини: 40 рядів (`bricks-sprint`) — хвиля 2

Соло-спринт на час на тому самому рушії, що й дуель «Цеглини». **Повний spec — [bricks.md](bricks.md)**: правила стіни (§2.1–2.5),
керування (§2.4, §6.4), журнал натисків (§3.1), вид і кадр (§4), модель симуляції й мережа (§5), клієнт (§6), тести спринту
(§8.3), детермінізм (§8.4). Тут — лише те, чим спринт відрізняється, щоб файл `<id>.md` існував для кожної гри пакета.

## Чим відрізняється від дуелі (bricks.md §2.10)

| | `bricks` | `bricks-sprint` |
|---|---|---|
| Старт | `ByHost`, відлік 75 тиків | `Immediate` → фаза `ready` («Натисни будь-яку клавішу») → `Input('ready')` → відлік 75 тиків → `go` |
| Гравітація | таблиця за етапом, росте | стало `G = 48` (1,25 клітинки/с) |
| Сміття | так | нема; `target = []`, посилок нема |
| Кінець | останній живий / раунди | фіксація з `lines ≥ 40`: час = `max(board.tick, wallTick − 30)` тиків → секунди з сотими → `Ctx.Score(0, sec)`, `Ctx.Finish([0], "Цеглини: Оля — 40 рядів за 1:37,35", scores: {0: тики})` |
| Завал | вибування | `Ctx.Finish([], "Цеглини: Оля — стіна впала, 23 ряди з 40")`, без `Score` |
| Бездіяльність | сервер веде стіну | 60 с без натисків у `go` → `Ctx.Finish([], "Цеглини: Оля — стіну покинуто")`, без `Score` |
| Ачівка | `bricks-four` | `bricks-sprint-2m` («Швидкий муляр», < 120 с) |
| Дії | `j`, `sync` | `j`, `sync`, `ready` («Уже почали», якщо не в `ready`) |
| Кадр/вид | §4 | ті самі форми, `boards` з однієї стіни, `wins = [0]`, `need = 1`, `garbage = 'none'` |
| Таблиця | перемоги (kind `wins`) | рекорд (kind `solo`, `order: lower`): секунди, наприклад `97.35`; картка показує `1:37,35` |
| «Ще раз» | каркасний `Rematch` | каркасний `Rematch` (для недобового соло є) → `Start()` → `ready`, нове зерно |
| Черепки | за партію платить каркас | не платить (соло) — лише ачівка |

## Екран

Стіна по центру (клітинка за формулою bricks.md §6.1), праворуч кишеня, три наступні, великий секундомір `m:ss,ff` і «рядів
23/40»; у `ready` — напис на стіні; відлік і «Поїхали!» як у дуелі. Керування — bricks.md §6.4 (будь-яка клавіша/кнопка/тап у
`ready` шле `ready`). Статус: `ready` — «Натисни будь-яку клавішу», `go` — «{lines}/40 · {m:ss}», кінець — текст результату.
