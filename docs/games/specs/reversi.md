# Реверсі (`reversi`, `reversi-glek`)

Класичне Отелло 8×8 двома режимами однієї плитки: **Удвох** (`reversi`, на рейтинг, годинник за бажанням) і
**З Глеком 🤖** (`reversi-glek`, соло без лобі, без рейтингу й черепків). Клієнт — один модуль `web/games/reversi.js`
(`reversi-glek` має `Client: "reversi"`; режим — за `ctx.room.game === 'reversi-glek'`, як у `chess.js`).

**Info.**
- `reversi`: `Title="Реверсі"`, `Accusative="реверсі"`, `Group=Board`, 2/2, `Rated=true`, `Options=[clock]` (`BoardClock.Option`).
  `SeatName`: 0 «чорні», 1 «білі».
- `reversi-glek`: `Title="Реверсі з Глеком"`, `Group=Solo`, 1/1, `TickMs=100`, `Start=Immediate`, `Private=true`, `Client="reversi"`.
  `SeatName`: 0 «ти», 1 «🤖 Дядько Глек».

## Правила

- Нотація Отелло: стовпці a–h зліва направо, рядки 1–8 **згори вниз**. Поле `i = (рядок − 1)·8 + стовпець`:
  0 = a1 (лівий верхній кут), 63 = h8. `ReversiCore.Name(i)` / `Parse("f5")`.
- Старт: білі d4 і e5, чорні e4 і d5. Першими ходять чорні; перші ходи — d3, c4, f5, e6.
- Хід: фішку ставлять на порожнє поле так, щоб хоча б в одному з 8 напрямків між нею і своєю фішкою стояв суцільний
  ряд чужих. Перевертаються всі такі ряди одразу. Порожнє поле чи край ряд обриває.
- **Пас автоматичний** (дії «пас» нема): якщо в того, чия черга, ходу нема, а в суперника є, черга лишається
  супернику, у виді `pass` = пропущене місце, у Журналі «⚪ білі пасують — ходити нікуди».
- Кінець: ходу нема ні в кого (повна дошка, хтось без фішок, або просто глухий кут). Рахують фішки; порожні поля
  **нікому не йдуть**. Рівно — нічия. Причина `wipe`, якщо в переможеного 0 фішок, інакше `count`.
- Ще кінці (лише `reversi`): здача `resign`, вихід з-за столу (`left`, техпоразка, як у шашках), прапорець годинника (`time`).
- `reversi-glek`: здача `resign` (Глек бере партію).

## Дії

| action | payload | Що робить / відмови (стан не міняють) |
|---|---|---|
| `move` | `{ cell: 0..63 }` (можна й `{ cell: "f5" }`) | «Не так швидко — зараз не твій хід» (Глек: «Глек думає — зачекай хвильку»), «Не зрозумів, куди ставити» (нема `cell`, поза 0..63, не ціле, криве ім'я, не об'єкт), «Поле вже зайняте», «Так не можна — нічого не перевертається», «Партію зіграно, тисни «Ану ще раз»» |
| `resign` | `{}` | Здатися. Після кінця — відмова. |
| `flag` | `{}` | Лише `reversi` з годинником: браузер шле, коли в когось упав прапорець. Без упалого — «Час ще є». Прапорець сервер перевіряє й на **кожній** дії (як у шашках). |
| `set` | `{ level?: "easy"\|"medium"\|"hard", color?: "black"\|"white"\|"turn" }` | Лише `reversi-glek`. Хоч одне поле має бути валідним, інакше «Не зрозумів налаштування». Посеред партії — **нова партія** з цим. Після кінця партії каркас сам відмовляє (`Say.Played`), тож «Нова партія» після кінця = `rematch`, а потім `set`, якщо щось міняли. |

Інша дія — «Тут так не ходять».

## Вид

Однаковий для всіх (глядачі теж бачать `legal`), `View(null)` = `View(0)` у `reversi`.

```
{
  board: "64 символи ('.' порожнє, 'b' чорна, 'w' біла), індекс = поле",
  turn: місце, чия черга | null (партію зіграно),
  toMove: "b" | "w" | null,              // колір того, чия черга
  legal: [поля],                          // ходи того, чия черга; [] після кінця (у Глека — лише коли хід людини)
  last: поле останнього ходу | null,
  flipped: [поля],                        // перевернуті останнім ходом, за зростанням індексу (не за відстанню!)
  pass: місце | null,                     // кого пропустили після останнього ходу; наступний хід знімає
  count: { b, w },
  moves: n,                               // поставлених фішок (паси не рахуються)
  clock: BoardClock.View | null,          // { ms: [чорні, білі], running, inc, total } — як у шашках; у Глека завжди null
  result: { winner: 0|1|null, reason: "count"|"wipe"|"resign"|"left"|"time", b, w } | null,
  series: Series.View | null,             // лише reversi: рахунок серії «Ще раз», як у шашках
  me: "b" | "w",                          // лише reversi-glek: колір людини
  glek: { level, color, thinking }        // лише reversi-glek
}
```

**Місця й кольори.** У `reversi` місце = колір: 0 — чорні завжди (після «Ще раз» місця обертаються, тож люди міняються
кольорами). У `reversi-glek` місце 0 — людина, 1 — Глек: `turn`, `pass`, `result.winner` — у цих місцях, а колір людини
дає `me` (для кольорів у шапці бери `toMove`/`me`, не `turn`).

## Глек (`ReversiEngine`)

Бітборди, альфа-бета, бюджет **вузлів** (не годинника) — партія за сідом відтворюється.

| Рівень | Як грає |
|---|---|
| `easy` легкий | На хід уперед: вага поля + кількість перевернутих + шум 0..30; 20 % ходів навмання; кут «бачить» у 2 випадках з 3. |
| `medium` звичайний | Ітеративне поглиблення до 3, 40 тис. вузлів, шум ±3 у корені. |
| `hard` сильний | Ітеративне поглиблення до 8, 160 тис. вузлів; з ≤ 12 порожніх — точний перебір до кінця («найшвидший першим»), якщо вкладається в бюджет. |

Оцінка: таблиця ваг (кути +100, X-поля −50, C-поля −20; коли кут зайнятий, штраф біля нього знімається) +
6 × різниця мобільності + під кінець (< 16 порожніх) різниця фішок. Кінець гри — ±100 000 + різниця фішок.
Глек ходить у `Tick` після паузи 600 + rng(400) мс, `_dirty` → `TickResult.Both`.

Журнал: «🤖 Глек пасує», «⚫ ти пасуєш — ходити нікуди», підсумок «Реверсі з Глеком: Оля ⚫ 40 : 24 ⚪ Глек (сильний)».
Репліки (не частіше ніж раз на 6 ходів): Глек узяв кут — «Кут мій!» / «О, кутик — дякую» / «Цей кут я давно пас»;
людина взяла кут — «Ой, віддав кут…» / «Ех, кут проґавив» / «Гарний кут, нічого не скажеш». Кінець з різницею ≥ 40:
«🤖 Та це розгром» або «🤖 Оце так рознесли Глека…».

## Кінець і нагороди (`reversi`)

- `Ctx.Finish([переможець] або [], "Реверсі: Оля ⚫ 38 : 26 ⚪ Петро")`, на `wipe` — з « — дошку витерто», нічия — « — нічия».
  Здача / прапорець / вихід — тексти як у шашках («… здається — Петро білі 1:0 Оля чорні»).
- Ело — каркас (`Rated`), черепки — каркас (від 6 ходів).
- Ачівки: `reversi-5` «Реверсист» ⚫ 30 — п'ять перемог (`WinRules`); `reversi-wipe` «Витер дошку» ⚪ 20 —
  `Ctx.Award(переможець, 0, "ach:reversi-wipe")` на `wipe`. Соло нагород не дає.
- `reversi` — настільна (`Board`, не соло), тож автоматично входить у «Настільний» (`all-boards`: перемога в кожній).

## Як реалізовано

Файли: `src/Hlechyky/Games/Impl/ReversiCore.cs`, `Reversi.cs`, `ReversiEngine.cs`, `ReversiGlek.cs`;
`Economy/Achievements.cs`; тести `tests/Hlechyky.Tests/Games/ReversiTests.cs`, `ReversiGlekTests.cs`.

Відступи й доповнення до плану (`D:/or-wt/_tools/reversi-plan.md`):
- Ядро на бітбордах (`ulong` на колір), ходи — зсувами з маскою стовпців a/h — Глеку треба ~3 млн вузлів/с.
- Додано поле `toMove` в обох режимах, `series` у `reversi`, `me` і `glek.thinking` у Глека — клієнту не треба вгадувати колір за місцем.
- У Глека `turn`/`pass`/`winner` — місця «людина 0 / Глек 1», а не кольори — так само, як у `chess-glek`.
- У Глека `legal` лише в хід людини (як у `chess-glek`) — щоб не підсвічувати дошку, поки Глек думає.
- `move` приймає й назву поля (`"f5"`) — зручно для MCP/ручних тестів, клієнт шле число.
- `set` без жодного валідного поля — відмова (у `chess-glek` мовчки ігнорувалось) — інакше клієнт не дізнався б про помилку.
- `flipped` — за зростанням індексу; затримку анімації за відстанню клієнт рахує сам від `last`.
- Пас при годиннику: `BoardClock.Moved` за пасовика повертає час тому, хто ходить знову; пасовик отримує надбавку `inc` — дрібниця, окремого методу не варта.
- Порожні поля в кінці нікому не йдуть (не WOF) — простіше пояснити, рахунок = фішки на дошці.
- Сильний рахує кінцівку точно з ≤ 12 порожніх лише коли вкладається в 160 тис. вузлів (з 12 порожніх — у більшості позицій;
  з ≤ 11 — завжди), інакше звичайний пошук на половині бюджету: найгірший хід ≈ 1,5 бюджету, ~60–90 мс у Debug.
- `Save/Load` (`Reversi.Position`) є, хоч гра не `Persistent`, — тести ставлять позиції тим самим шляхом, що в шашках.
- Ачівку-вайп перевіряє тест через `h.Awards`; `Room.Result.Winners` у Глека порожній, коли виграв Глек (його нема за столом) — клієнт бере `view.result.winner`.

Сила (тести на фіксованих сідах): сильний б'є легкого ≥ 8/10, звичайний легкого ≥ 7/10, сильний звичайного ≥ 6/10
(на ділі 9/10 з різницею ~50 фішок). Perf-тест: сильний Глек ≤ 120 мс (Debug) на серединці, 13 і 12 порожніх.

**Пастки для клієнта.**
- Після кінця партії в Глека `set` не пройде (каркас: «партію зіграно») — «Нова партія» = `rematch`, далі `set`.
- `turn: null` після кінця; `legal: []`.
- Анімацію перевороту запускати лише коли змінився `last` (вид приходить і на тики Глека, і на годинник).
- `pass` тримається до наступного ходу — показувати тост лише на зміну (`last` + `pass`).
- Рядки 1–8 згори вниз (не як у шахах): `board[0]` — a1 у лівому верхньому куті.

Як перевірити: `dotnet test tests/Hlechyky.Tests --filter "FullyQualifiedName~Reversi"`. Руками — етап Б (клієнт).
