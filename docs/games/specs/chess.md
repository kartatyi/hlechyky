# Шахи (`chess`) — пункт 22

**Info:** `Id="chess"`, `Title="Шахи"`, `Accusative="шахи"`, `Group=Board`, 2/2, `Rated=true`,
`Options=[variant: classic|960|anti]`, `Hint="Класика, шахи Фішера (фігури на першій лінії перетасовано) або піддавки (хто позбувся всіх фігур — виграв)"`.
`SeatName(0)="білі"`, `SeatName(1)="чорні"`. Місце 0 — білі в першій партії; «Ще раз» обертає місця (каркас), тож білі чергуються.

## Правила

**Класика.** Повні правила ФІДЕ: ходи всіх фігур, рокіровка (обидві), взяття на проході, перетворення
(за замовчуванням ферзь; payload може вказати `promo: q|r|b|n`), шах/мат/пат, нічия: пат, недостатній
матеріал (K vs K, K+B vs K, K+N vs K, K+B vs K+B однопольні), правило 50 ходів (автоматично), триразове
повторення (автоматично, за позицією+черга+права рокіровки+ен-пасан-поле). Немає годинника.

**Фішера (960).** Початкова розстановка: сід із `Ctx.Rng` → одна з 960 позицій (король між турами, слони
на різнопольних). Рокіровка за правилами 960: король і тура їдуть на класичні кінцеві поля (g1/f1 або c1/d1),
усі поля між (і кінцеві) вільні від інших фігур, король не проходить через биті поля. Хід рокіровки в
payload — `from` = король, `to` = тура (стандарт для 960 у lichess) АБО `castle: "K"|"Q"`; приймати обидва.

**Піддавки (anti).** Взяття обов'язкове (є вибір серед взять). Шаху нема, король — звичайна фігура (може
битись, перетворюватись у короля теж можна). Рокіровки нема. Перемога: у гравця не лишилось фігур АБО він
не має жодного ходу (пат = перемога тому, хто в паті). Нічия: лише повторення/50 ходів.

## Дії (`Act`)

| action | payload | Умови | Помилки |
|---|---|---|---|
| `move` | `{ from: "e2", to: "e4", promo?: "q" }` | своя черга, легальний хід | «Зараз не твій хід», «Так не ходять», «Треба вказати, у кого перетворити» (якщо промо без promo — беремо ферзя, помилки нема) |
| `resign` | — | партія йде | суперник виграв: Журнал «шахи: X здався, Y 1:0 X» |
| `draw` | — | пропозиція нічиєї; якщо суперник уже пропонував (і не зробив хід після) — нічия | інакше `Ok("Запропонував нічию")`, у виді `drawOffer: seat` |
| `decline` | — | зняти пропозицію суперника | — |

## Вид (`View(seat)`) — публічний (Hidden=false)

```ts
{
  variant: 'classic'|'960'|'anti',
  board: string,           // 64 символи, a8..h8, a7.. → h1; 'KQRBNP' білі, 'kqrbnp' чорні, '.' порожньо
  fen: string,             // повний FEN (для дебагу і тестів)
  turn: 0|1,               // місце, чия черга (не колір!) — каркасу для «Твій хід»
  toMove: 'w'|'b',
  legal: { from: string, to: string, promo?: string }[],  // легальні ходи ТОГО, ХТО ХОДИТЬ (обом видно — інформація публічна)
  lastMove: { from, to } | null,
  check: boolean,
  captured: { w: string, b: string },   // взяті фігури, напр. 'pp n' — для рядка над дошкою
  moves: string[],         // SAN-нотація ходів для списку («e4», «Nf3», «O-O», «exd5», «e8=Q+»)
  halfmove: number, fullmove: number,
  drawOffer: 0|1|null,
  result: null | { winner: 0|1|null, reason: 'mate'|'stalemate'|'resign'|'material'|'fifty'|'repetition'|'agreed'|'left'|'anti-nopieces'|'anti-nomoves' }
}
```

## Завершення й Журнал

- Мат: `Finish([winner], "шахи: Оля білі 1:0 Петро чорні (мат на 34-му ході)")`.
- Нічия: `Finish([], "шахи: Оля і Петро зіграли внічию (пат)")`.
- Виплата: каркас (WinReward/DrawReward/PlayReward). `MinRewardMoves=6` півходів — коротша партія
  (здався на 2-му ході) без нагороди.

## Клієнт (`web/games/chess.js`, `chess.css`)

- Дошка 8×8 CSS-grid, клітинки `--panel2/--bg2`, фігури — Unicode ♔♕♖♗♘♙ (білі `--text`, чорні
  `--accent`... ні: білі `#f5f0e6`, чорні `#1b1b1b` з обведенням, щоб читались на зеленому). Дошка
  повертається для чорних (місце 1 бачить себе внизу). Глядач — білі внизу.
- Клік/тап по фігурі → підсвітити `legal` ходи з неї; клік по цілі → `act('move')`. Перетягування —
  необов'язково. Перетворення: попап із 4 фігурами.
- Над дошкою: взяті фігури; під — список ходів (прокрутка), кнопки «Здатись», «Нічия?».
- Останній хід підсвічений, шах — червоне тло короля.
- Мобільний: дошка `min(92vw, 420px)`.

## Тести (`ChessTests.cs`, ≥ 40)

- **Перфт** із початкової позиції: depth 1 = 20, 2 = 400, 3 = 8 902, 4 = 197 281 (depth 4 — `Trait Perf`,
  має вкластись у 10 с). Перфт «Kiwipete» `r3k2r/p1ppqpb1/bn2pnp1/3PN3/1p2P3/2N2Q1p/PPPBBPPP/R3K2R w KQkq -`:
  d1 = 48, d2 = 2 039, d3 = 97 862.
- Рокіровка: заборонена через шах, через бите поле, після руху короля/тури; дозволена на порожній лінії.
- Ен-пасан: доступний тільки одразу після подвійного ходу; знімає правильну пішку.
- Перетворення у 4 фігури; мат перетворенням.
- Мат-у-1 із відомої позиції; пат; недостатній матеріал (усі 4 випадки); 50 ходів; триразове повторення.
- Піддавки: взяття обов'язкове (хід без взяття при наявному взятті — Fail); перемога без фігур; пат = перемога.
- 960: 20 випадкових сідів → позиція валідна (K між R, слони різнопольні); рокіровка в 960 на 3 позиціях.
- `resign`, `draw`+`draw` = нічия, `draw`+хід = пропозиція знята.
- Вид: `legal` порожній після Finish; `board` довжина 64; `turn` = місце, а не колір (після рематчу перевірити).
- Детермінізм: партія з 20 ходів → той самий FEN.

## Реалізація — підказки

- Внутрішнє представлення: `int[64]` або 0x88; генерація псевдоходів + фільтр «король під боєм».
- SAN — для списку ходів; не обов'язково розбирати SAN на вході (payload координатний).
- Повторення: `Dictionary<string,int>` за ключем `fen без лічильників`.
- Не тягнути NuGet-бібліотек шахів: правила свої, вони ж тестуються.
